## 摘要

本文件收錄**常駐介面**的固定設計模式，範圍包括頁面外框、側邊欄、頁首、清單頁的工具列與表格、按鈕、狀態徽章與膠囊，以及全站共用的「燕麥奶茶」色票。浮層另見 [對話窗 UI 設計規範](對話窗%20UI%20設計規範.md)，浮層包括對話窗、二次確認框、通知與消息條，以及編修視窗與 AI 問答這類全螢幕工作窗。兩份文件共用同一組色票與同一套 z-index 規則：色票與外框層級以本文件為準，對話窗的尺寸、鍵盤與確認行為以另一份為準。

本文件的內容都已對照 `src/MeetingRecord/MeetingRecord.Web/**` 的現行原始碼核對。速查表 [開發慣例與限制速查](開發慣例與限制速查.md) 的 §6.1（UI 慣例）與 §6.4（堆疊層級）仍是硬性紅線，本文件是它們的展開版。以下路徑都相對於 `src/MeetingRecord/MeetingRecord.Web/`。

## 一、樣式寫在哪裡 ⚠️

**判準是「這個元素由誰渲染、落在 DOM 的哪裡」，不是元件名稱。**

| 情形 | 位置 | 理由 |
|---|---|---|
| 色票 token、z-index 變數 | `wwwroot/app.css` 的 `:root` | 只有真正的全域 `.css` 能寫 `:root` |
| AntDesign 元件的強調色覆寫（`.ant-btn-primary`、`.ant-input`、`.ant-pagination-*`…） | `wwwroot/app.css`，一律加 `body` 前綴 | 全站一致；見第四節 |
| 跨多個元件共用的 class（`.btn-icon-label`、`.markdown-content`） | `wwwroot/app.css` | 抄多份必漏，而且全域樣式不受 scope 限制 |
| 用 `:has()` 跨元件比對的規則（收合鈕讓路） | `wwwroot/app.css` | 放在 scoped CSS 裡會被加上本元件的 scope 屬性，比對不到別的元件 |
| 對話窗外框（`.ant-modal*`、尺寸分級） | `Components/Commons/FormModalHelper.razor` 的全域 `<style>` | Modal 是 portal DOM，scoped CSS 打不到，見對話窗規範 |
| 元件或檢視自己寫的 markup | 各自的 `.razor.css`，顏色一律 `var(--oat-*)` | CSS isolation |
| AntDesign 子元件的內部元素 | 從**自己寫的容器**用 `::deep` 選進去 | 見 1.2 |

### 1.1 載入順序

`Components/App.razor` 的 `<head>` 順序：

```
bootstrap.min.css → app.css → MeetingRecord.Web.styles.css（scoped bundle）
→ favicon → HeadOutlet → _content/AntDesign/css/ant-design-blazor.css → Google Fonts（Material Icons 五種字型）
```

⚠️ **AntDesign 的 CSS 比 `app.css` 晚載入**，同特異度的 `.ant-*` 規則會被它蓋回去。本專案**刻意不調整載入順序**，因為那會連帶影響 bootstrap 與 `app.css` 既有的基礎規則。做法是讓 `app.css` 的每一條 `.ant-*` 覆寫都以 `body` 開頭，把特異度墊高一級（0,0,1,1 對 0,0,1,0）。停用態 AntDesign 用的是 `.ant-btn-primary[disabled]`（0,0,2,0），同樣靠 `body` 前綴才壓得過。

scoped bundle 雖然也排在 AntDesign 前面，但 scoped 選擇器本身多帶一個 `[b-xxxxx]` 屬性選擇器，特異度天生較高。側邊欄的 `::deep .ant-menu-*` 另外加了 `!important`，那是為了壓過 AntDesign 寫在子元素上的宣告（見第五節）。

### 1.2 scoped CSS 的兩個坑 ⚠️

1. **`.razor.css` 裡不要寫 `:root`。** CSS isolation 會把它改寫成 `:root[b-xxxxx]`，而 `<html>` 由 `App.razor` 輸出、身上沒有任何 scope 屬性，所以整組變數永遠選不到。0.4.41 之前登入頁就是這樣讓欄位標籤變成白字白底，對比 1.00:1。元件要宣告自己的變數時，掛在最外層容器上，例如 `Login.razor.css` 的 `.login-container` 把 `--accent`、`--ink` 等別名指向 `var(--oat-*)`。
2. **scope 屬性不會傳進子元件。** 樣式掛在 AntDesign 元件的 `Class` 上時，`.foo {}` 會被編成 `.foo[b-xxxxx]`，永遠選不到，而且不會報錯。正確寫法是從自己 `.razor` 裡寫的元素用 `::deep` 選進去，範例見 `CrudActionButton.razor.css` 的 `.crud-action-button-host ::deep .crud-action-button`。要確認規則有沒有生效，直接看 `obj/Debug/net10.0/scopedcss/bundle/MeetingRecord.Web.styles.css`：scope 屬性應該落在容器上，子選擇器不帶屬性。

## 二、燕麥奶茶色票 ⚠️

**唯一來源是 `wwwroot/app.css` 的 `:root`（0.4.41 建立）。** 元件一律用 `var(--oat-*)` 取用，不要另外寫死色碼。

| Token | 值 | 用途 |
|---|---|---|
| `--oat-50` | `#EEE5DE` | 最淺的奶油底：頁面漸層兩端、`.markdown-content` 底色、停用的主按鈕底、中性膠囊（`.meeting-status-none`、`.status-toggle-tag-disabled`）的底、操作鈕 hover 底 |
| `--oat-100` | `#E3D4C7` | 頁面漸層中段、側邊欄漸層、下拉選單選中項底、處理中徽章（`.meeting-status-processing`）的底 |
| `--oat-200` | `#DBC8B7` | 側邊欄頁首漸層下緣、**側邊欄 hover**、分區分隔線、卡片外框、使用者選單項 hover、Markdown 的 `code`／`pre`／`th` 底 |
| `--oat-300` | `#D4BDA8` | **側邊欄選中態**（深棕字對比 6.4:1）、側邊欄右框線、中性膠囊外框、操作鈕 hover 外框、Markdown 表格框線 |
| `--oat-400` | `#C7AA8F` | 聚焦外框（`.btn:focus`、收合鈕 `:focus-visible`）、側邊欄捲軸、處理中徽章外框、停用操作鈕的圖示色 |
| `--oat-500` | `#C2A284` | 最深的奶茶色。用在登入頁、`FileDropZone`、`SplashView`、AI 問答的裝飾元素；AntDesign 覆寫裡的 hover 與聚焦外框寫的是它的字面值 |
| `--oat-ink` | `#43362C` | **主文字色與主色**：主按鈕底、勾選與滑桿、頁首標題、選中項文字、收合鈕底。這是延伸色，不在使用者給的六色內 |
| `--oat-ink-mid` | `#7A6A5A` | 次要文字：副標、區塊標題、未選中的選單圖示、操作鈕預設色、連結色。也是延伸色 |
| `--oat-surface` | `#FFFFFF` | 浮出面板的白底，例如收合態側邊欄的飛出子選單 |
| `--oat-ok` / `--oat-ok-bg` | `#6B7A4A` / `#EDF0E4` | 成功：完成徽章、啟用膠囊、進度列成功態 |
| `--oat-warn` / `--oat-warn-bg` | `#B07D3A` / `#FAF0DF` | 警示：等待中徽章 |
| `--oat-err` / `--oat-err-bg` | `#A6483C` / `#F7E8E5` | 錯誤與破壞性動作：失敗徽章、刪除操作鈕、「管理員」徽章、使用者選單項文字 |
| `--z-app-header` | `100` | 頁首 `.top-row`（見第八節） |
| `--z-app-sidebar` | `101` | 收合態側邊欄 |
| `--z-app-sidebar-toggle` | `102` | 側邊欄收合鈕 |

### 2.1 為什麼一定要有 `--oat-ink`／`--oat-ink-mid`

使用者給的六色**全部是淺色**，最深的 `#C2A284` 配白字對比只有 2.4:1，遠低於 WCAG AA 要求的 4.5:1。深棕 `#43362C` 在六色上都過 AA（4.9:1～9.4:1），是這組色系裡唯一可用的文字色，所以主按鈕、選中態與文字一律採用「深棕」或「淺奶茶底配深棕字」。不要把白字壓在任何一個 `--oat-50`～`--oat-500` 上。

### 2.2 語意色調暖，但不轉成奶茶色

AntDesign 預設的螢光綠 `#389e0d`、紅 `#cf1322`、橘 `#d46b08` 在奶茶底上太跳，所以改用同明度的暖色：橄欖綠、磚紅、赭黃。成功、警示、錯誤三種狀態仍然一眼可辨，**不要為了統一而把它們染成奶茶色**。全站唯一保留的外來色是登入頁 Google 按鈕的四色品牌 logo。

### 2.3 必須寫字面色碼的兩個地方

| 位置 | 為什麼不能用 `var()` | 規則 |
|---|---|---|
| `wwwroot/app.css` 的 AntDesign 強調色區塊 | 其實可以用；刻意保持與 AntDesign 原始碼相同的字面形式，方便日後與上游 diff | 檔頭註解列出對照：`#43362C`＝`--oat-ink`、`#55463A`＝hover、`#362B23`＝active、`#C2A284`＝`--oat-500`、`#E3D4C7`＝`--oat-100` |
| `Components/Commons/Charts/ChartPalette.cs` | SVG 的 `fill` 是逐片以行內樣式產生的，必須是實際色碼 | `Success`／`Warning`／`Danger` 對應 `--oat-ok`／`-warn`／`-err`；`NeutralRamp` 從 `--oat-ink` 排到 `--oat-200` |

⚠️ **調整色票時，這兩處要一起改**，目前沒有測試會擋。

## 四、頁面外框與側邊欄

### 4.1 外框（`Components/Layout/MainLayout.razor(.css)`）

| 元素 | 規格 |
|---|---|
| `.page` | `--oat-50 → --oat-100 → --oat-50` 縱向漸層。桌機（≥ 641px）改成橫向排列，`--sidebar-width` 展開是 300px、收合是 64px |
| `.top-row`（頁首） | 半透明白底加 `backdrop-filter: blur(14px)`，`min-height: 4.5rem`，底線 `rgba(67, 54, 44, 0.10)`。桌機 `position: sticky`、`z-index: var(--z-app-header)` |

### 4.2 側邊欄（`Components/Layout/NavMenu.razor(.css)`）

**選中態是一塊「比側邊欄底色深一階」的圓角色塊，沒有色條、沒有陰影**（0.4.45 定案）。0.4.41 試過深棕整塊（使用者覺得違和），0.4.44 試過淡奶油底加左側色條（標記感太弱），兩版都已否決。

| 狀態 | 規則 |
|---|---|
| 一般項 | `--oat-ink` 字、`border-radius: 14px`、高 3rem、圖示 `--oat-ink-mid` 1rem |
| hover | `--oat-200` 底。**必須比選中態淺一階**，否則兩者分不出來 |
| 選中（含已展開的父項） | `--oat-300` 底、`--oat-ink` 字、`font-weight: 600`、圖示轉 `--oat-ink` |
| 區塊標題 `.nav-section-title` | `--oat-ink-mid`、0.75rem、全大寫、字距 0.12em；第二個以後加 `--oat-200` 頂線（`.nav-section-title-subsequent`） |
| 頁首品牌區 `.top-row` | 高度與底線必須與 `MainLayout` 的 `.top-row` **完全一致**（4.5rem＋1px），否則兩條邊界錯開。標誌是 `favicon.svg` 同一份線稿，以 `currentColor` 描邊；系統名稱讀 `SystemSettings`，不寫死 |

兩個一定要保留的修正（0.4.44）：

- **`.sidebar-menu-shell ::deep .ant-menu-item a { color: inherit !important; }`**：AntDesign 的 `MenuItem RouterLink` 渲染成 `<a>`，那個 `<a>` 自己帶主色藍。父層寫再多 `!important` 也蓋不到子元素自己的宣告，所以必須直接對 `<a>` 下 `inherit`。
- **`.ant-menu-item::after { display: none !important; }`**：關掉 AntDesign inline 選單在右緣畫的那條藍色指示線。

收合態（桌機）的規則：

- 區塊標題隱藏，改用 `.collapsed-section-divider` 分隔線維持分區；品牌區只留 2.5rem 標誌。
- 圖示按鈕 `.collapsed-menu-trigger` 套同一組色：hover `--oat-200`、選中 `.collapsed-menu-item-active` `--oat-300`。
- 飛出子選單 `.collapsed-menu-flyout` 用 `--oat-surface` 白底、`z-index: 40`（在側邊欄的堆疊脈絡內），透明的 `::before` 負責橋接 hover。顯示條件**不含** `:focus-within`，否則點擊子項後焦點會黏住、選單收不起來。
- 收合時 `.nav-scrollable-collapsed` 改成 `overflow: visible`，飛出選單才不會被裁掉。

### 4.3 側邊欄收合鈕

`.sidebar-toggle-edge` 由 `MainLayout.razor` 渲染，放在 `.sidebar` **外面**，因為 `.sidebar` 有 `overflow: hidden`，放在裡面就無法跨出邊界。

- 桌機：`position: fixed`，`left: var(--sidebar-width)`，垂直置中並 `translate(-50%, -50%)`，騎在側邊欄右緣上；`z-index: var(--z-app-sidebar-toggle)`。
- 手機：浮在標題列內**靠右**（0.4.56 修正，原本靠左會壓住品牌標誌）。
- **滑過選單時讓路**（0.4.111）：`app.css` 的 `.page:has(.collapsed-menu-item:hover) .sidebar-toggle-edge` 與 `:focus-visible` 版本讓收合鈕淡出並設 `pointer-events: none`，否則它剛好落在某個選單項上時，滑鼠移向飛出子選單會先碰到它而中斷 hover。這條規則**必須放在 `app.css`**，原因見第一節。

### 4.4 選單圖示

- `Datas/Menu.json` 的 `icon` 必須是 **classic Material Icons** 名稱。`App.razor` 載的是 `Material+Icons*` 系列字型，Material Symbols 專有名稱（`database`、`monitoring`、`query_stats`）會渲染成破圖。`MenuIconTests` 負責擋這件事。
- `NavMenu.razor.cs` 的 `GetMaterialIconKind` 會把少數舊別名轉成實際圖示，例如 `dashboard → space_dashboard`、`shield_person → security`、`ProjectFilled → workspaces`；空值時父項用 `folder_open`、葉項用 `article`。

## 五、按鈕 ⚠️

**按鈕的文字規則看有沒有外框**（0.4.62 起；0.4.57～0.4.61 是「全站一律有文字」）。

| 類型 | 規則 | 實作 |
|---|---|---|
| **有外框**：工具列、對話框按鈕 | 一律「圖示＋可見文字」。只寫 `Tooltip` 或 `title` 不夠，因為觸控裝置叫不出來 | `<span class="btn-icon-label"><MaterialIcon … /><span>新增</span></span>`；`.btn-icon-label` 在 `app.css`，負責 `inline-flex`、`gap: 6px`，並把 Material Icon 從預設 24px 縮到 1rem |
| **無外框**：清單「操作」欄 | 只放圖示，用途靠 `Tooltip` 表達 | 一律用 `Components/Commons/CrudActionButton.razor`（`Title`＋`Icon`，可加 `Danger`、`Disabled`、`Href`），不要自己刻 |
| **狀態膠囊**：本身就是控制項 | 見第六節 | `StatusToggleTag` |

`CrudActionButton` 的規格（`CrudActionButton.razor.css`）：28px 方形、透明框、`--oat-ink-mid` 圖示 16px；hover 時改成 `--oat-300` 框加 `--oat-50` 底；`Danger` 用 `--oat-err` 字，hover 改 `--oat-err-bg` 底。`.crud-action-button-label` 是用 clip 隱藏的無障礙標籤，也是 `<Button>` 分支唯一的可及名稱，**不要因為畫面上看不見就刪掉它**。專案頁一列最多有 6 顆，帶文字會把 `Fixed="Right"` 欄撐到 500px 以上，這就是操作欄只留圖示的原因。

明文例外：

- **右下角背景工作進度面板**（`BackgroundJobProgressPanel`）的四顆按鈕雖然無外框，仍保留文字。同一列的「取消」會真的中止工作，「關閉」只是移除通知，行為完全不同，只留圖示容易誤按。
- 以下三處純圖示是設計本身，不是省略標籤：側邊欄收合鈕、收合態的選單觸發鈕、使用者選單的下拉箭頭（`aria-hidden`）。它們都有 `aria-label` 或 `title`。

**圖示一律用 `MaterialIcon`，不要用 emoji**。emoji 的字型、大小與基線由作業系統決定，跟旁邊的文字對不齊。

## 六、狀態徽章與膠囊

所有膠囊共用同一個外形：`display: inline-block; padding: 2px 10px; border-radius: 10px; font-size: 12px;`，再加 1px 同色系外框。

### 6.1 處理狀態徽章（唯讀）

會議清單的「轉錄狀態」與「會議紀錄」兩欄，由 `MeetingViewView.razor.cs` 的 `GetStatusCssClass`／`GetDraftStatusCssClass` 對應 class，樣式在 `MeetingViewView.razor.css`：

| 狀態 | class | 字／底／框 |
|---|---|---|
| 未處理、**已取消** | `.meeting-status-none` | `--oat-ink-mid`／`--oat-50`／`--oat-300` |
| 等待中 | `.meeting-status-pending` | `--oat-warn`／`--oat-warn-bg`／`--oat-warn` |
| 處理中 | `.meeting-status-processing` | `--oat-ink`／`--oat-100`／`--oat-400` |
| 完成 | `.meeting-status-completed` | `--oat-ok`／`--oat-ok-bg`／`--oat-ok` |
| 失敗 | `.meeting-status-failed` | `--oat-err`／`--oat-err-bg`／`--oat-err` |

- **「已取消」刻意沿用中性灰。** 取消是中性結果，switch 裡明寫 `Cancelled => "meeting-status-none"`，免得日後有人把它當成遺漏而改成紅色。
- 顯示文字來自 `MeetingRecord.Share` 的 `TranscriptionStatusText.Describe`／`DraftStatusText.Describe`。列舉值漏寫文字時會落到 `_ => "未知"`，畫面不報錯也不警告，由 `StatusTextTests` 擋。
- 處理中時，徽章旁會用 `.meeting-status-percent` 顯示即時百分比，失敗時用 `.meeting-status-error-hint` 顯示錯誤提示。

### 6.2 啟用／停用膠囊（可點）

使用者、團隊、分類清單（0.4.105 起）共用 `Components/Commons/StatusToggleTag.razor`，提示詞清單是 0.4.64 的原型。新頁面請直接用元件，不要再複製一份樣式。

| 項目 | 規則 |
|---|---|
| 顏色 | 啟用 `.status-toggle-tag-enabled`（`--oat-ok` 系）；停用 `.status-toggle-tag-disabled`（中性灰，與 `.meeting-status-none` 相同） |
| 權限 | 有動作權限（`CanToggle`）才渲染成 `<button>`；**沒權限就渲染回 `<span>`**，不要用 `<button disabled>`，否則它無法 focus，`aria-label` 也讀不到 |
| 文案 | 可見文字講**狀態**（「啟用」），`aria-label` 與 `title` 講**動作**（「點擊改為停用」） |
| 字型 | 原生 `<button>` 不繼承字型，要補 `font: inherit`；而 `font: inherit` 也會重設字級，所以要再補一次 `font-size: 12px` |
| 確認 | 會寫入資料，所以由呼叫端在 `OnToggle` 裡做 `ConfirmAsync`；非破壞性的「啟用」方向不套 `Danger`，「停用」才套（見對話窗規範） |

### 6.3 只切換檢視的膠囊

目前只有待辦頁負責人面板的四顆（0.4.85 起）。它們只改檢視、可逆、不碰資料庫，所以**不要二次確認**，但要遵守三條規則：

- 用 `aria-pressed` 並給**字串** `"true"`／`"false"`。
- 0 筆的膠囊渲染回 `<span>`。
- 選中的那顆加內框與粗體，**其餘膠囊 `opacity: .5`**。

完整規則見速查表 §6.1。

## 七、清單頁與表格

- **表格沒有全站主題。** 9 個清單頁的 `<Table>` 都吃 AntDesign 預設樣式，加上第三節的分頁與勾選覆寫。各頁 `.razor.css` 的 `.xxx-view-toolbar`／`-toolbar-left`／`-toolbar-right` 只負責 flex 版型。
- 工具列的按鈕一律是有外框的 `ButtonType.Default`（或 `Primary`）加 `.btn-icon-label`，例如 `CategoryViewView.razor` 的「新增」「重新整理」「清空搜尋」「搜尋」。
- 「操作」欄一律寫成 `<ActionColumn Fixed="ColumnFixPlacement.Right">`，裡面放 `CrudActionButton`。⚠️ **沒有 `ScrollX` 的表格，`Fixed` 不會生效。** 目前只有待辦頁設了 `ScrollX="870px"`。要開 `ScrollX` 之前，先確認頁首層級正確，也要確認它不大於雙欄版面中最窄的容器寬，否則固定欄左緣會出現陰影線並蓋住鄰欄。細節見速查表 §6.4。
- 角色清單的斑馬紋（`.role-view-table-wrap`）寫在 `FormModalHelper.razor` 的全域 `<style>` 尾端，標註為「與 modal 無關，沿用原位置」。
- Markdown 內容一律掛 `.markdown-content`（`app.css`），樣式包括 `--oat-50` 底、`--oat-200` 的 `code`／`pre` 底、`--oat-300` 的表格框線，`code` 用 `color: inherit` 蓋掉 Bootstrap 的粉紅。⚠️ 它的 `max-height: 60vh` 是給對話框內預覽用的；整頁手冊或左右分欄編輯器要用 `::deep` 解除（見 `HelpView.razor.css`、`MarkdownEditorModal.razor.css`）。

## 八、堆疊層級（z-index）⚠️

全站外框的 `z-index` **一律用 `app.css` 的三個變數**，不要自己挑數字：

| 元素 | 值 | 位置 |
|---|---|---|
| 頁首 `.top-row` | `var(--z-app-header)`＝100 | `MainLayout`／`NoFooterLayout`／`EmptyLayout.razor.css` |
| 收合態側邊欄 | `var(--z-app-sidebar)`＝101 | `MainLayout.razor.css` 的 `.page.sidebar-collapsed .sidebar` |
| 側邊欄收合鈕 | `var(--z-app-sidebar-toggle)`＝102 | `MainLayout.razor.css`；必須高於側邊欄，否則左半邊被蓋掉 |
| 背景工作進度面板、`#blazor-error-ui` | `1000`（字面值） | 刻意與 modal 同層 |
| 使用者下拉選單／收合飛出選單 | `20`／`40` | 只在父層的堆疊脈絡內比較 |

取值依據是 AntDesign 1.6.0 **實際用到的值**：表格固定欄 2～3、`.ant-affix` 10、欄寬拖拉 99、`.ant-modal-mask`／`-wrap` 1000、`.ant-message`／`.ant-notification` 1010、各種下拉選單 1050。所以外框要 **> 99**（壓過所有表格內部圖層）且 **< 1000**（讓對話框、通知與下拉選單仍蓋在外框之上）。

⚠️ **父層的 z-index 會困住子層。** 0.4.68 之前頁首是 `z-index: 1`，裡面的使用者選單即使寫 `z-index: 20` 也逃不出那個堆疊脈絡，結果表格固定欄（2）蓋過整個選單。子層寫再大都沒用，要改的是建立堆疊脈絡的那個父層。浮層那一側的層級見 [對話窗 UI 設計規範](對話窗%20UI%20設計規範.md) 第十二節。
