# 會議紀錄新增/修改對話框改為近滿版與雙欄排版（0.4.28）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.4.28
- 首次實作版本：0.4.28
- 最後核對日期：2026/08/27

## 變更目的

「會議紀錄」的新增/修改對話框沿用 AntDesign `Modal` 預設寬度（520px、無高度上限），表單欄位（標題、日期、描述、分類、團隊、影音檔）由上往下單欄堆疊後總高超過視窗，導致對話框被截斷、必須靠**外層遮罩**滾動才能看到底部與確認按鈕。

本次改為：對話框近似滿版（上下左右各留少量留白）、內容區自身可滾動、較短的欄位兩欄併排。

## 根因

`MeetingViewView.razor` 的 `Modal` 只設了 `Class="meeting-view-modal"`，但 `FormModalHelper.razor` 的共用樣式群組（90vw/90vh + `ant-modal-body` 可滾動）只列出 `.role-view-modal`、`.my-user-modal`、`.project-view-modal`，未包含 `.meeting-view-modal`，因此完全套不到尺寸與內部滾動規則。

註：`.meeting-view-modal` 這類「AntDesign 自身渲染的外框」無法寫在 `MeetingViewView.razor.css`（Blazor CSS 隔離會加上 `[b-xxxxx]` 屬性，而外框元素由 `Modal` 元件渲染、拿不到本元件的 scope 屬性），故一律集中在 `FormModalHelper.razor` 的全域 `<style>`——沿用既有做法。

## 本次修改

- `Components/Commons/FormModalHelper.razor`
  - 將 `.meeting-view-modal` 加入既有共用群組（外框尺寸、`ant-modal-content` 垂直 flex、header/footer 不縮、`ant-modal-body` `overflow-y: auto`）。
  - 新增 `.meeting-view-modal` 專屬覆寫：`width/max-width: 96vw`、`top: 2vh`、內容高度 `96vh`（即上下左右各留少量留白的近滿版）。
  - 新增雙欄排版樣式：`.meeting-view-form-grid` 為兩欄 grid（`column-gap: 24px`），`.meeting-view-form-full` 佔滿整列；`max-width: 768px` 時退回單欄。
- `Components/Views/Meetings/MeetingViewView.razor`
  - 表單欄位以 `<div class="meeting-view-form-grid">` 包住（欄位順序不變）。
  - 「描述」與「影音檔」加上 `Class="meeting-view-form-full"` 佔滿整列；「會議標題／會議日期」與「分類／團隊」各自兩欄併排。
- `appsettings.json`：`SystemVersion` `0.4.27 → 0.4.28`。

僅調整版面，未變更任何欄位繫結、驗證規則、上傳流程或 API。

## 驗證

- `dotnet build -t:Compile`：0 錯誤（Razor 標記與 `@@media` 轉義通過編譯；因本機正在執行 `MeetingRecord.Web`、輸出檔被鎖定，故以 `-t:Compile` 略過複製步驟）。
- 待手動核對（需重建 + Ctrl+F5）：於 `/meetings` 按「新增」，對話框應近滿版、外層頁面不出現滾動軸、欄位過長時由對話框內容區自行滾動；視窗縮至 768px 以下應退回單欄。
