# 登入頁品牌識別改為 AI 會議記錄小助手（0.4.30）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.4.30
- 首次實作版本：0.4.30
- 最後核對日期：2026/08/28

## 變更目的

登入頁沿用腳手架的預設品牌識別 —— 名稱是「Blazor 專案範本」、slogan 在講玻璃擬態與動態漸層、LOGO 是一個泛用的綠色圓角方塊、瀏覽器分頁標題寫「身分驗證」。這些都在描述**範本本身**，而不是這個系統實際在做什麼。

本次把登入頁的品牌識別換成產品自己的：名稱、slogan、LOGO、分頁 icon 四項一次到位。

## 本次修改

- `Components/Auths/Login.razor`
  - `<PageTitle>`：`身分驗證` → `AI 會議記錄小助手`（這同時就是瀏覽器分頁標題）。
  - `<h1 class="app-title">`：`Blazor 專案範本` → `AI 會議記錄小助手`。
  - slogan：改為「上傳會議影音，自動轉成逐字稿，讓會議紀錄不再靠人工聽打。」刻意只描述**已實作**的能力——「套用提示詞產生會議紀錄草稿」尚未串接，不寫進 slogan。
  - LOGO：綠色圓角方塊＋四角星，換成 AI 原子線稿（三條交疊橢圓軌道＋中央 `AI` 字樣＋四個軌道節點）。
- `Components/Auths/Login.razor.css`
  - `.brand-logo` 移除半透明底襯、外框、內陰影與 padding，只保留尺寸與間距。線稿風格的圖示加底襯會顯得雜。
- **新增** `wwwroot/favicon.svg`：同一組線稿，固定用品牌綠 `#22c55e`。
- `Components/App.razor`：`<link rel="icon">` 改以 SVG 優先，保留既有 png 作為舊瀏覽器 fallback。
- `Components/Views/Commons/SplashView.razor`：品牌圖示來源由 `/favicon.png` 改為 `/favicon.svg`。
- `appsettings.json`
  - `SystemSettings.SystemInformation.SystemName`：`會議紀錄系統` → `AI 會議記錄小助手`（顯示於右上角「關於」對話窗）。
  - `SystemVersion` `0.4.29 → 0.4.30`。

## 兩個實作決策

**LOGO 線稿用 `stroke="currentColor"`**，而非寫死顏色。`Login.razor.css` 定義的是深色漸層底＋近白色文字（`--login-bg-1: #0f172a`、`--login-text: #f8fafc`），讓線稿繼承 `.brand-panel` 的 `color`，不論實際渲染成深底或淺底都保證有對比，也不必為了配色再開一組變數。favicon 版本則例外——它顯示在瀏覽器分頁列、拿不到頁面的 `color`，所以固定用品牌綠。

**四個軌道節點畫成實心圓點**，而不是原始參考圖的「白底外框圓」。底襯移除後版面背景是半透明的，白色填充會突兀；且 favicon 縮到 16px 時空心小圓會糊成一團，實心點在小尺寸下仍可辨識。

**favicon 用 SVG 而非覆蓋既有 png**：本機沒有 SVG→PNG 的點陣化工具（無 ImageMagick／Inkscape），硬轉會失真。現代瀏覽器均支援 SVG favicon，舊瀏覽器仍可退回既有的 `favicon.png`。
