# 登入頁與主框架改為燕麥奶茶色系（0.4.41）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.4.41
- 首次實作版本：0.4.41
- 最後核對日期：2026/09/03

## 變更目的

使用者反映登入頁「帳號密碼等欄位顯示不清楚」，並指定燕麥奶茶色票（`#EEE5DE` / `#E3D4C7` / `#DBC8B7` / `#D4BDA8` / `#C7AA8F` / `#C2A284`），範圍涵蓋**登入頁與登入後的主框架**，另要求網頁 icon 使用專案 logo。

## ⚠️ 「顯示不清楚」的根因是一個 CSS isolation bug

`Login.razor.css` 第 1 行原本寫 `:root { --login-bg-1: … }`。**Blazor 的 CSS isolation 會把「每一個」選擇器都加上 scope 屬性**，實際產生：

```css
:root[b-58c85dswx8] { --login-bg-1: #0f172a; … }
```

`:root` 是 `<html>`，由 `App.razor` 輸出，而 `App.razor` 沒有對應的 `.razor.css`，所以 `<html>` 身上**沒有任何 `b-…` 屬性** → 選擇器永遠選不到 → **12 個色彩變數全部 undefined**。

`var()` 未定義時該宣告等同 `unset`，連鎖後果：

| 元素 | 原意 | 實際渲染 | 對比 |
|---|---|---|---|
| 背景漸層 | 深藍綠 | **transparent** → 露出 Bootstrap 白底 | — |
| `.form-label`（**寫死 `#ffffff`**） | 深底白字 | **白字疊白底** | **1.00:1** |
| `.error-message`（**寫死 `#fecaca`**） | 深底淺紅 | 淺紅疊白底 | **1.45:1** |
| `.form-input` 邊框 | — | `rgba(15,23,42,.22)` 疊白 | **1.61:1** |

**帳號／密碼／驗證碼三個標籤字面上是隱形的**。修法：變數改定義在 `.login-container`（元件自己的元素，會帶 scope 屬性），並在檔案開頭留警告註解。

同時修掉第二個 isolation bug：`.remember-me input` 產生為 `.remember-me input[b-…]`，但該 `<input>` 由 `<InputCheckbox>` 子元件渲染、不帶父元件 scope，規則無效。改用原生 `<input type="checkbox">`——靜態 SSR 下渲染結果相同，且 `:checked` 選擇器可用來做勾選動畫。

## ⚠️ 色票必須擴充兩個值，否則文字無法閱讀

使用者提供的六色**全部是淺色**，最深的也只是中淺駝色：

| 色票 | 白字對比 | 深棕字對比 |
|---|---|---|
| `#EEE5DE` | 1.3:1 ✗ | **9.4:1** ✓ |
| `#E3D4C7` | 1.5:1 ✗ | **8.1:1** ✓ |
| `#DBC8B7` | 1.7:1 ✗ | 7.2:1 ✓ |
| `#D4BDA8` | 1.9:1 ✗ | 6.4:1 ✓ |
| `#C7AA8F` | 2.2:1 ✗ | 5.3:1 ✓ |
| `#C2A284` | **2.4:1 ✗** | **4.9:1** ✓ |

**白字在任何一色上都不及格**（WCAG AA 需 4.5:1）。因此加入兩個同色系的自然延伸：

- **深棕 `#43362C`（`--oat-ink`）** — 主文字色，在全部六色上都過 AA
- **中棕 `#7A6A5A`（`--oat-ink-mid`）** — 次要文字與 placeholder

主按鈕、驗證碼區塊、側邊欄選中態一律用**深棕底 + 最淺奶油字**（9.4:1）——這是這組淺色系裡唯一能做出強對比的組合，不需引入任何外來色。

## 全域色票

新增於 `wwwroot/app.css`（**全域非 scoped，`:root` 在這裡才有效**）：

```css
:root {
    --oat-50 … --oat-500      /* 使用者提供的六色 */
    --oat-ink / --oat-ink-mid  /* 必要的深色延伸 */
    --oat-ok / --oat-warn / --oat-err  /* 調暖後的語意色 */
}
```

全站元件一律 `var(--oat-…)` 取用，不再各自硬編色值。

### 語意色調暖

AntDesign 預設的螢光綠 `#389e0d`、紅 `#cf1322`、橘 `#d46b08` 在奶茶底上過於突兀，改為同明度的暖色版本：橄欖綠 `#6B7A4A`、磚紅 `#A6483C`、赭黃 `#B07D3A`，各配對應的淺底。狀態仍可一眼分辨，但融入色系。

**唯一保留的外來色是 Google 登入按鈕的四色品牌 logo**（品牌規範不可改），它只是白底卡片上的小圖示。

## 網頁 icon 改為專案 logo

`App.razor` 同時引用 SVG 與 PNG。`favicon.svg` 早已是專案 logo（三橢圓 + AI 字），但 **`favicon.png` 一直是 Blazor 樣板的預設圖示**——0.4.30 的 changelog 明載當時「本機無 ImageMagick/Inkscape，硬轉會失真」所以刻意沒動。

現在有解：**用 headless Edge 把 SVG 渲染成 PNG**（開一個內嵌 SVG 的 HTML，設 180×180 視窗後截圖）。兩個檔案的主色一併改為深棕 `#43362C`。

⚠️ **但只換檔案不夠**——`App.razor` 原本是 `href="favicon.svg"` 這種固定路徑，沒有 fingerprint，而**瀏覽器對 favicon 的快取極度頑固**：檔案換了，分頁上仍顯示舊的樣板紫色圖示。改走 `@Assets["favicon.svg"]` 之後路徑帶了內容雜湊（`favicon.qrzc1fpupv.svg`），內容一變路徑就變，快取自然失效。

## 底部音波帶

登入頁底部一條貫穿全寬的音波帶（76 根膠囊狀色條）。這是把會議錄音轉成文字的工具，所以動態直接取材自主題，而不是通用的漸層流動。

參數是調過的——第一版 `scaleY(0.86 → 1)`、6 秒週期，幅度只有 14%，實際上看不出在動。現在：

```
@keyframes waveBounce { 0%,100% { scaleY(0.4) }  50% { scaleY(1.15) } }
animation: waveBounce 1.5s cubic-bezier(0.36, 0.07, 0.19, 0.97) infinite;
animation-delay: calc(var(--i) * -0.02s);
```

**相位差是關鍵**：週期 1.5s 搭配每根 -0.02s 的延遲，76 根剛好涵蓋一個完整週期，所以看起來是一道波浪橫向推過去，而不是每根各自亂跳。條子改為全圓角膠囊，視覺上更輕快。

`prefers-reduced-motion: reduce` 時整條靜止但保留造型。

## 其他保留的修正

- 補上 `prefers-reduced-motion`（舊版三個無限循環動畫沒有退場機制）
- `.app-title` / `.login-title` 明確指定 `color`——AntDesign 與 Bootstrap 的 reset 都會對 `h1`/`h2` 設 color，只靠父層繼承會被蓋掉
- flex/grid item 補 `min-width: 0`，避免被內容撐開而溢出
- 刪除三處純裝飾文案：`ENTERPRISE ACCESS`、`Welcome Back`、`企業級安全登入`；`使用者登入` 改為 `登入`
- slogan 改為單行顯示：原本 `max-width: min(46ch, 100%)` 在中文字型下約等於 386px，會把一句話斷成兩行
- 移除 `errorMessage` 欄位（唯一用途是掛 `alert-danger`，而 Bootstrap 5.3 的 `.alert-danger` 沒有 `.alert` 就不產生任何可見樣式）

## 實作備註（給後續維護）

- **scoped `.razor.css` 裡絕對不要寫 `:root`**——會變成 `:root[b-xxxxx]` 而選不到 `<html>`。要定義全站共用變數請放 `wwwroot/app.css`（全域非 scoped）。這個坑已經害過一次，害整組色票從未生效。
- **換 favicon 一定要同時確認它走 `@Assets`**。沒有 fingerprint 的話，瀏覽器會一直沿用舊圖，你會以為檔案沒換成功。
- CSS 動畫的幅度與週期要以「實際看得出來」為準。`scaleY(0.86 → 1)` 配 6 秒在畫面上等同靜止；要形成橫向波浪，相位差總跨度應該接近一個完整週期（本例 76 根 × 0.02s ≈ 1.5s）。
- 側邊欄選中態底色改深後，**文字色必須同步改淺**。批次 `sed` 換背景時很容易漏掉配對的 `color`，本次就先做出過深棕底配深灰字的組合。
- `NoFooterLayout` 與 `EmptyLayout` 都殘留著 Blazor 樣板的 `.sidebar` 深藍紫漸層，但這兩個版面根本沒有 sidebar 元素，是純死碼。本次一併移除。
