## 變更目的

使用者指出系統不該有任何「只用圖示表達」的按鈕。盤點後確認範圍比想像大：
**六個清單頁的工具列是 emoji、所有清單「操作」欄的文字被 CSS 藏起來、
背景工作進度面板的四顆鈕也只有圖示。**

純圖示按鈕的問題不只是不好認：用途全寫在 `Tooltip`／`title` 裡，
而**這兩者在觸控裝置上根本叫不出來**，等於那些按鈕沒有標籤。

## 一、六個清單頁工具列：emoji → 圖示＋文字

`MyUserView`、`RoleViewView`、`CategoryViewView`、`MeetingViewView`、
`PromptTemplateViewView`、`TeamViewView` 的工具列原本是四顆 emoji：

| 原本 | 改為 |
|---|---|
| ➕ | `add` ＋「新增」 |
| 🔄 | `refresh` ＋「重新整理」 |
| ❌ | `close` ＋「清空搜尋」 |
| 🔍 | `search` ＋「搜尋」 |

順手把 emoji 換成 `MaterialIcon`，與 `ProjectViewView`／`TodoViewView`／`DashboardView`
一致——emoji 的字體、大小與基線都由作業系統決定，跟旁邊的文字對不齊。

`TodoViewView`（新增／重新整理／清空搜尋／搜尋）與 `ProjectViewView`
（新增專案／編輯專案／刪除專案／重新整理）本來就是 `MaterialIcon`，補上文字即可。
另外補了專案附件清單的「下載」鈕——那顆是漏網的。

### 新增全域樣式 `.btn-icon-label`

放在**非 scoped 的** `wwwroot/app.css`，因為有 8 個以上的元件要用；
抄 8 份的話日後改一處必定會漏。全域樣式也不受 scope 屬性限制，
選得到 `MaterialIcon` 渲染出來的 span（scoped CSS 得多寫 `::deep`）。

`AiChatModal` 的「送出」與 `DashboardView` 的「重新整理」本來就是這個形狀，
只是各自寫在自己的 scoped CSS 裡；這一版把它變成全站共用的樣式名。

## 二、清單「操作」欄：文字從隱藏改為可見

`CrudActionButton` 是八個清單頁共用的操作鈕。它**本來就有** `Title` 文字，
但 `.crud-action-button-label` 是這樣寫的：

```css
position: absolute; width: 1px; height: 1px;
clip: rect(0, 0, 0, 0);
```

——典型的「螢幕閱讀器可見、視覺隱藏」寫法。畫面上只剩一個 18px 圖示。改為正常顯示。

### 一併修掉的第二個 scope 陷阱

`.crud-action-button` 這一整組樣式掛在 AntDesign `<Button>` 上，
而 scope 屬性不會傳進子元件——所以 `<Button>` 那一支的樣式**從來沒有生效過**
（`<a>` 那一支是自己寫的元素，反而是有效的）。

解法與 0.4.56 相同：外層包一個自己寫的 `<span class="crud-action-button-host">`，
所有選擇器改從它 `::deep` 進去，兩支就都涵蓋了。已從產出的樣式包確認：

```
crud-action-button-host[b-hxbhocm6ub]  .crud-action-button
```

### 欄位變寬的處理

專案頁一列最多五顆（檢視／編修／匯出 PDF／逐字稿／問答）。AntDesign 的 `.ant-space`
沒有 `flex-wrap`，不限寬的話這個 `Fixed="Right"` 的欄位會撐到 500px 以上，
把表格推出畫面。在 `app.css` 限制表格儲存格內的 `.ant-space` 為 `max-width: 22rem`
並允許換行，排成兩行——列高變高，但比整張表橫向捲動好。

## 三、背景工作進度面板

四顆鈕（收合／展開、全部關閉、取消、關閉）原本都是 26px 方形純圖示，
用途只寫在 `aria-label` 與 `title`。改為圖示＋文字，面板寬度 320px → 380px。

`title` 屬性保留——它現在是補充說明（例如關閉鈕的
「關閉通知（工作會繼續執行）」），不再是唯一的說明。

## 四、刪掉 8 條已無意義的 CSS

八個檔案裡各有一條一模一樣的 `*-icon-button { width: 36px; padding: 0; ... }`。
按鈕加上文字之後，方形圖示鈕這個形狀本來就不該存在。

值得記一筆：**其中 7 條原本就是死的**——同樣掛在 AntDesign `<Button>` 的 `Class` 上，
選不到（唯一有效的是 0.4.56 才用 `::deep` 修好的 `.project-view-icon-button`，
這一版連它一起移除）。也就是說那些工具列按鈕一直都是 AntDesign 的預設尺寸，
從來沒有變成過 36px 方形。

`.project-view-icon-button-danger:hover`（刪除專案的紅色 hover）保留。

## 五、刻意保留的三處純圖示

不是漏改，是這三處的圖示就是設計本身：

| 位置 | 理由 |
|---|---|
| 側邊欄收合鈕（`MainLayout`）| 0.4.44～0.4.50 依使用者提供的參考圖定案的圓形箭頭，加文字會破壞那個設計 |
| 收合態的側邊欄選單觸發鈕（`NavMenu`）| 側邊欄收合時「只顯示圖示」正是收合的用途 |
| 使用者選單的下拉箭頭（`MainLayout`）| 該按鈕已經顯示使用者名稱與「管理員」標籤，箭頭是 `aria-hidden` 的裝飾，不是獨立按鈕 |
