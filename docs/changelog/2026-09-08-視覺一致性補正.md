## 變更目的

0.4.35 的燕麥奶茶配色改版只改了自家寫的 CSS，**AntDesign 元件的預設藍全部原封不動**。
盤點時另外查出兩個缺陷，其中一個是我自己在 0.4.44 造成的。三件事一起補：

1. 全站的強調色（primary 按鈕、滑桿、進度列、勾選框……）仍是 AntDesign 預設藍
2. `ProjectViewView` 有三條 scoped CSS **從來沒有生效過**
3. 手機版的側邊欄收合鈕壓在品牌標誌上

## 一、AntDesign 強調色改為奶茶色系

規則加在**非 scoped 的** `wwwroot/app.css`。

### 為什麼每條都要加 `body` 前綴

AntDesign 的 CSS 在 `App.razor` 是第 22 行載入，**比 `app.css`（第 12 行）晚**。
同特異度的 `.ant-btn-primary` 會被它蓋回去，所以一律以 `body` 把特異度墊高一級
（0,0,1,1 對 0,0,1,0）。

另一個選項是把 `app.css` 移到 AntDesign 之後——但那會連帶影響 bootstrap 與本檔既有的
基礎規則，風險大得多，不值得為了少打幾個 `body`。

停用態 AntDesign 用的是 `.ant-btn-primary[disabled]`（0,0,2,0），所以也要 `body` 前綴。

### 兩個刻意的例外

- **停用態不套主色**：停用的按鈕看起來就該是停用的，改成淡奶茶底＋40% 透明度的墨色。
- **進度列的成功態留綠色**，但改用色票裡的 `--oat-ok`（#6B7A4A）而不是 AntDesign 的
  #52c41a——不然完成的瞬間會從棕色跳成一個不在色票內的綠。

主色 #43362C（`--oat-ink`）配白字，對比 **11.6:1**，遠高於 AA 的 4.5:1。

順帶清掉三處殘留的模板藍：`app.css` 的 `a/.btn-link`（#006bb7）、`.btn-primary`（#1b6ec2）、
`.btn:focus` 外框（#258cfb），以及 `MainLayout.razor.css` 使用者選單的
`rgba(37, 99, 235, .45)` 聚焦外框。

## 二、三條從未生效的 scoped CSS

`.project-view-project-select`、`.project-view-icon-button`、
`.project-view-icon-button-danger:hover` 都掛在 AntDesign 元件的 `Class` 上。

**Blazor CSS 隔離的 scope 屬性不會傳進子元件**（0.4.43 用
`EmitCompilerGeneratedFiles` 查證過），所以這三條會被編成
`.project-view-icon-button[b-jwhvaz7ric]` 而永遠選不到——工具列那四顆圖示鈕
**從來沒有套到預期的 36px 方形樣式**。

`Class` 本身確實有被 AntDesign 套到渲染出的元素上，缺的只是 scope 屬性。
所以從自己寫的 `.project-view-picker` 容器用 `::deep` 選進去即可，**標記完全不用改**：

```css
.project-view-picker ::deep .project-view-icon-button { ... }
```

驗證方式是直接看產出的樣式包
（`obj/Debug/net10.0/scopedcss/bundle/MeetingRecord.Web.styles.css`）：

```
project-view-picker[b-jwhvaz7ric]  .project-view-icon-button
```

scope 屬性落在容器上、子選擇器沒有——這才是能命中的形狀。

## 三、手機版收合鈕壓住品牌標誌

**這是 0.4.44 我自己造成的缺陷。** 那一版把收合鈕移出側邊欄改成浮動，桌機版掛在外緣中間，
但手機版（`max-width: 640.98px`，側邊欄寬度是 100%）保留了 `left: 1rem; top: 1.15rem`
——而標題列的品牌標誌也在左上角。

改為 `right: 1rem`，桌機斷點裡補一條 `right: auto` 讓 `left: var(--sidebar-width)`
仍然生效。
