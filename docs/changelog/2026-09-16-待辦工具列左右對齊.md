# 待辦事項工具列左右對調，與其他清單頁一致（0.4.74 → 0.4.75）

使用者回報：「待辦事項上方功能請左右交換，新增、重新整理移至左邊，其餘功能移至右邊，讓整個系統更統一。」

## 確認：待辦是唯一相反的一頁

實際盤過全部七個有工具列的清單頁：

| 頁面 | 左 | 右 |
| --- | --- | --- |
| 使用者、角色、分類、會議紀錄、提示詞範本、團隊 | 新增／重新整理 | 搜尋、過濾 |
| **待辦事項（改版前）** | **搜尋、過濾** | **新增／重新整理** |

所以這不是偏好問題，是待辦頁單獨違反了既有慣例。

## 改法

`TodoViewView.razor` 把 `.todo-view-toolbar-left` 與 `.todo-view-toolbar-right` 兩個區塊的**內容對調**。

**沒有動任何 CSS**——`-left` 與 `-right` 的樣式規則本來就完全相同（都是
`display:flex; align-items:center; gap:8px; flex-wrap:wrap`），左右位置是由外層
`justify-content: space-between` 決定的，所以搬內容就夠了。

## 刻意不做的事

**沒有統一「搜尋」與「清空搜尋」的前後順序。**

其他頁是「清空搜尋」排在「搜尋」之前，待辦是相反。但「清空搜尋」是**條件顯示**的
（有關鍵字才出現），排在「搜尋」前面會讓使用者一打字，「搜尋」按鈕就往右跳一格。
待辦目前的順序反而比較穩定，不該為了對齊多數而改成比較差的那個；
要統一的話應該是反過來改其他六頁，那超出這次的範圍。
