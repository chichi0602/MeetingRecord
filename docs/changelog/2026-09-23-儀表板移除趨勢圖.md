# 儀表板移除「近 N 天趨勢」折線圖（0.4.95 → 0.4.96）

使用者回報：

> 儀錶板那頁近30天趨勢顯示的功能好像沒什麼意義 新增的會議跟完成紀錄有需要呈現在儀表板上嗎

---

## 為什麼拿掉而不是換一張

1. **兩條線幾乎重疊。** 上傳 → 轉錄 → 生成通常幾分鐘內跑完，「新增會議」與「完成紀錄」大多落在同一天，雙線沒有對照價值。
2. **量太小。** 每天 0～3 場，30 天裡大部分是 0，畫出來是一條貼地的鋸齒線，看不出趨勢。改成按週或按月分桶只會讓線平滑一點，重疊的問題還在。
3. **資訊已經有了。** 「會議紀錄」卡片有「本月新增 N」，轉錄／生成狀態圓餅已涵蓋完成與失敗數。
4. **切天數的代價不小。** 切換會重新載入整份 summary，連 AI 問答語料也被重掃一遍。

「換成可直接點去處理的待處理清單（失敗的轉錄／生成、逾期待辦）」有討論過，這次先不做。

## 異動

- `DashboardView`：移除折線圖與天數下拉（`TrendDayOptions`、`trendDays`、`OnTrendDaysChangedAsync`）。「處理效能」直接接在提示詞範本／儲存空間之後。
- `DashboardService.GetSummaryAsync` 拿掉 `trendDays` 參數與 `DefaultTrendDays`；`DashboardSummary` 移除 `Trend`。
- `DashboardMetrics.BuildDailyTrend` 與它的 4 個單元測試一起刪除。

⚠️ **以下刻意保留，不是漏刪**：`TrendPoint`、`DashboardMetrics.BuildDayBuckets`／`BuildDayLabels`、`LineChart.razor`。AI 用量分析頁的「本月累計 vs 上月同期」曲線（`AiUsageMetrics.BuildMonthToDateCumulative`）還在用。
