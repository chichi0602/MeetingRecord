# 專案項目工具列改一行，新增團隊與狀態篩選（0.4.105 → 0.4.106）

使用者回報：

> 專案項目那邊要能用團隊或分類過濾。現在的下拉太長了，請縮短，讓它們在一行顯示：左側放新增、編輯、刪除、AI 問答（移除重新整理），右側放團隊、分類、狀態（已完成、未開始等）的過濾。

原本的工具列有兩個問題：

- 專案下拉最小寬度 260px。
- 「依分類篩選」是多選，又沒有固定寬度，選了幾個分類就一路撐寬，整排被擠到換行。

---

## 版面

| 位置 | 內容 |
|------|------|
| 左側 | 專案下拉（寬 200px）、新增專案、編輯專案、刪除專案、AI 問答 |
| 右側 | 團隊、分類、狀態三個篩選（各寬 140px） |

- 「重新整理」按鈕移除，只被它使用的 `OnRefreshAsync` 一併刪除。
- 三個篩選都可以多選，並設 `MaxTagCount=1`：只顯示第一個選項，其餘收成「+N」，寬度固定，不會再把整排撐到換行。
- 窄螢幕時，左右兩組各自換行，不會破版。

## 篩選規則

- 三個篩選同時成立；同一個篩選選了多個時，符合任一即可。
  - **團隊**：專案的主責或協作團隊有任一選取的團隊。選項是全部啟用中的團隊。
  - **分類**：專案貼了任一選取的分類。
  - **狀態**：未開始、進行中、已完成、暫緩、等待。
- 篩選只在畫面上縮小專案下拉的清單，**不影響誰看得到**。清單本來就已依團隊權限過濾。
- 目前選的專案被篩掉時，自動切到篩選結果的第一筆。篩選結果是空的時候，會清掉選取並顯示空狀態提示；清空篩選後，自動選回第一筆。
