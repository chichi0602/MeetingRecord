# 專案工具列的三個篩選改回同一行（0.4.106 → 0.4.107）

使用者回報：

> 右側三個可以跟新增專案那些在同一行，但三個不是三列，是一行呈現，現在這樣很醜。

0.4.106 的團隊、分類、狀態篩選，被排成上下三列，而且整組被擠到下一行。

## 原因

0.4.106 的寬度（140px）是用隔離樣式的 `::deep .project-view-filter` 選進元件庫的下拉元件。這個寫法沒有生效：每個篩選都撐滿整個右側區塊，所以變成一個一列，整組又被擠到下一行。

## 修改

- 三個篩選改成直接在元件上寫 `Style="width: 140px;"`，和專案裡其他工具列篩選的寫法相同。
- 拿掉沒有生效的 `.project-view-filter` 樣式。
- 右側那組設為 `flex-wrap: nowrap`，三個篩選固定排成一行。
- 外層仍允許換行：螢幕寬度不夠時，整組篩選才會換到下一行，不會破版。

## 測試

- 網站建置 0 錯誤。這次只改畫面，沒有新增測試。
- 需要實測：寬螢幕時，左側的專案、新增、編輯、刪除、AI 問答，和右側的團隊、分類、狀態，全部在同一行。
