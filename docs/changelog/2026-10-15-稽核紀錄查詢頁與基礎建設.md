- 首次實作版本：1.0.32

比照 NET10-Blazor-Starter 的「稽核紀錄」功能，分三批交付。這是第一批：讓既有的 `AuditLog` 有畫面可以看，並補上來源 IP、索引與保留期限。第二批補帳號安全事件與權限拒絕，第三批補業務資料事件。規格見 [稽核紀錄 PRD](../prd/稽核紀錄-prd.md)。

## 一、選單與權限

- 「系統管理 → 帳號與權限」底下新增「稽核紀錄」（id 40，`fact_check`，`/audit-logs`），排在使用者管理、角色管理之後。
- **只限管理者**：頁面以 `CheckIsAdmin()` 守門；側邊欄 `SidebarMenuService.AdminOnlyMenuIds` 加入 40；不在權限目錄、不能勾給角色。
- `MagicObjectHelper.角色_稽核紀錄` 只是與 `Menu.json` name 對齊的名稱常數，不是權限鍵。

## 二、稽核紀錄頁（`/audit-logs`）

- **篩選**：發生時間起訖（含時分秒）、動作（中文名稱，選項取自資料）、結果、操作者帳號、來源 IP（前綴）、關鍵字。按「查詢」才套用。
- **工具列**：查詢、重新整理、匯出 CSV（最多 10,000 筆）、清除 N 天前、全部清除（都要確認）。
- **表格**：發生時間（本地）、結果、動作（中文膠囊，依類別上色，滑過顯示代碼）、操作者、來源 IP、目標、摘要、查看。伺服器端分頁，只有發生時間可排序。
- **明細窗**：本地與 UTC 時間、動作名稱與代碼、操作者、IP、目標類型與識別、摘要全文。
- **自我稽核**：匯出寫 `Audit.Export`；清除、全部清除在刪除之後寫 `Audit.Purge`、`Audit.ClearAll`。
- 刻意沒有單筆刪除、沒有 Web API。

## 三、基礎建設

- **動作代碼集中**：新增 `Share/Helpers/AuditActions.cs`（常數＋中文對照）。既有約 35 個呼叫點改用常數，**代碼值完全不變**，舊資料照樣對得上。
- **資料表**：`AuditLog` 新增 `ClientIp`（最長 64）與 `OccurredAt`、`Action`、`(ActorUserId, OccurredAt)` 三個索引；migration `AddAuditLogClientIpAndIndexes`。
- **來源 IP**：新增 `IClientIpProvider`／`ClientIpProvider`。`ApplicationCircuitHandler` 在 Blazor 連線建立與重連時記下 IP；HTTP 請求（登入頁、Web API）直接取連線 IP。呼叫端都不用改。
- **寫入服務改用自己的 context**：`AuditLogService` 改注入 `DbContextOptions<BackendDBContext>`，每次寫入自己 new 一個短命 context。修掉兩個隱患：
  - 以前 SaveChanges 會順便存掉呼叫端 context 裡還沒存的變更。
  - 以前寫入失敗時那筆稽核留在追蹤器裡，下一次存檔被重送。
- **保留期限**：`LogRetentionSettings:AuditLogDays`（預設 365，0＝不自動清）；新增 `AuditLogRetentionBackgroundService`，每天清一次，有刪才寫 `Audit.AutoPurge`。門檻用 UTC。
- **查詢服務**：新增 `AuditLogQueryService`，UTC↔本地轉換集中在這裡。

## 四、設定

```json
"LogRetentionSettings": {
  "ExceptionLogDays": 90,
  "AiUsageLogDays": 0,
  "AuditLogDays": 365
}
```
