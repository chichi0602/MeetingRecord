# 產生會議紀錄對話框滿版（1.1.59 → 1.1.60）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：1.1.60
- 首次實作版本：1.1.60
- 最後核對日期：2026/11/13

使用者回報：

> 產生會議記錄這邊 所屬專案跟底下的與會人員都會卡住無法完全顯示 請修改 讓這邊盡量滿版就不會有這個問題

---

## 一、原因

會議紀錄頁的「產生會議紀錄」對話框原本是 `form-modal-compact`（寬 680px，高度隨內容縮）。裡面只有四個欄位，整個對話框大約只有六百多 px 高。

所有對話框的外框都設了 `overflow: hidden`（標題與按鈕固定、只有內容區捲動，見[對話窗 UI 設計規範](../architecture/對話窗%20UI%20設計規範.md)第三節），所以「所屬專案」「與會人員」的下拉清單往下展開時，超出對話框底部的部分會被切掉，連「開始產生」按鈕也被蓋住。

## 二、修正

- `Web.Client/Pages/Meetings/MeetingPage.razor`：`Class="form-modal-compact"` 改成 `Class="form-modal-large meeting-draft-request-modal"`，寬度變成 90vw。
- `FormModalHelper.razor` 新增 `.meeting-draft-request-modal .ant-modal-content { height: 92vh }`，高度固定佔滿畫面，下拉清單有空間往下展開。用 92vh 是因為對話框頂端已經離畫面上緣 4vh，4 ＋ 92 ＝ 96vh。
- 寫法跟 AI 問答（`ai-chat-modal`）、會議紀錄視窗（`markdown-editor-modal`）一樣：尺寸 class 管寬度，另外加一個 class 固定高度。`ModalSizeClassTests` 只要求剛好一個尺寸 class，新 class 不算尺寸 class。
- 專案頁的「產生會議紀錄」是頁面上的區塊，不是對話框，不受影響。

## 三、未處理

- 「歸屬到專案」對話框（同一個檔案）同樣是 `form-modal-compact`，裡面也有專案下拉。專案多的時候可能一樣會被切掉，這次沒改。

## 四、驗證

- 會議紀錄頁 → 一筆逐字稿 →「產生會議紀錄」：對話框約 90% 寬、接近整個畫面高；展開「所屬專案」看得到全部專案；選了專案之後「與會人員」清單完整顯示；「開始產生」按鈕看得到。
