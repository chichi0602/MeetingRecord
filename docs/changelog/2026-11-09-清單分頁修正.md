# 清單分頁修正（1.0.56 → 1.0.57）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：1.0.57
- 首次實作版本：1.0.57
- 最後核對日期：2026/11/09

使用者要求（WASM 遷移前置工作 C，見 [09-Blazor-WASM-遷移評估與測試策略](../planning/09-Blazor-WASM-遷移評估與測試策略.md) §4.9）：

> 修六個清單頁分頁 bug

---

## 一、原因

- `Category`／`Meeting`／`MyUser`／`Project`／`RoleView`／`Team` 六支服務的 `GetAsync(DataRequest)` 把 `Take` 包在 `if (dataRequest.Take != 0)` 裡，而清單頁一律傳 `Take = 0`，所以從來沒有分頁：第 1 頁列出全部資料、第 N 頁列出「第 N 頁以後的全部」。分頁器的總數是在切頁前算的，一直是對的，所以不容易發現。
- 現在只是畫面多幾列；改成 WASM 後會變成整張表從網路傳下來，遷移前先修。
- 提示詞清單（0.4.64）與待辦清單（0.4.85）早已修好，這次補齊其餘六支。

## 二、修改

- 六支服務改成與 `PromptTemplateService` 相同的寫法：`Skip(...).Take(PageSize)`，不再看 `DataRequest.Take`。修改前確認這六支方法除了各自的清單頁與測試沒有別的呼叫端（下拉選單、匯出、API 都走別的方法），不會讓任何地方少拿資料。
- 分類、團隊、角色、使用者管理、會議紀錄五個清單頁：
  - `ReloadAsync` 尾端補**頁碼夾住**：停在最後一頁時把唯一一筆刪掉，自動回到前一頁，不會顯示空白表格（`Math.Max(1, ...)`，AntDesign 在頁碼小於 1 時不觸發換頁）。
  - `OnTableChange` 明確寫回 `_pageSize = args.PageSize`，改每頁筆數確實生效（提示詞清單也補上）。
  - 會議紀錄頁保留「背景重新載入時保留勾選」的既有行為。
- 專案服務的 `GetAsync(DataRequest)` 目前沒有清單頁使用，一樣修正以免日後踩到。
- 移除 `PromptTemplateService`／`TodoService` 註解裡「其餘 6 支仍是舊寫法」的過時說明。
- 文件：[開發慣例與限制速查](../architecture/開發慣例與限制速查.md) §6.2、[系統功能總覽](../architecture/系統功能總覽.md)、[畫面與欄位字典](../guides/畫面與欄位字典.md) §0.5、09 號評估 §4.9。
- 版本 1.0.56 → 1.0.57。
