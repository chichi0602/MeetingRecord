# WASM 遷移 M2：儀表板搬到 WASM（1.1.11 → 1.1.12）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：1.1.12
- 首次實作版本：1.1.12
- 最後核對日期：2026/11/10

使用者要求：

> M2 剩下的工作一次做完（1.1.12～1.1.14 連續做、每版自動 commit），接著做 M3。

---

## 一、原因

- 照前幾頁的做法把儀表板搬到 WASM。
- 儀表板的資料型別（`DashboardSummary`、`ChartSlice` 等）放在 Business，圖表元件放在 Web，WASM 專案拿不到。

## 二、修改

- **資料型別搬到 `MeetingRecord.Dtos/Dashboards`**：伺服器的 `DashboardService`、AI 用量分析，與 WASM 頁、圖表元件共用同一份；兩個計算屬性（顯示文字、儲存總量）標成不序列化。
- **圖表元件搬到 WASM 專案**（長條、折線、圓餅、統計卡、配色），命名空間不變；仍是舊版頁面的 Token 用量、資料庫用量、日誌等級照用。
- **圓餅的幾何計算搬到 Share**（`ChartGeometry`），伺服器端原方法改成轉呼叫，既有測試不動。
- **新增 `GET /api/v1/dashboard`**：只需登入（0.4.97 起儀表板登入即可看），回全公司彙總數字；呼叫者看不到的專案名稱併成「其他專案」，以 API 呼叫者自己的資料範圍判斷。
- **儀表板頁搬到 WASM**：`Web.Client/Pages/Dashboards/DashboardPage`，畫面不變；`WasmRoutes` 加 `/dashboard`。
- 文件：[開發慣例與限制速查](../architecture/開發慣例與限制速查.md) §1（共用資料型別放 Dtos）、[儀表板 PRD](../prd/儀表板-prd.md)、[Web API 端點目錄](../architecture/Web%20API%20端點目錄.md)、[認證授權與權限機制](../security/認證授權與權限機制.md)、Token 用量 PRD、畫面與欄位字典、介面視覺規範、09 號「十、之三」。
- 版本 1.1.11 → 1.1.12。

## 三、測試

- 新增 `DashboardApiTests`：沒登入 401；一般使用者看得到自己專案的名稱、別人的併成「其他專案」；改成管理者後全部看得到。
- 授權守門白名單加儀表板 API 並寫明理由。
- 端對端：DSH-01、DSH-02 一行不改照過；以儀表板為起點的 NTF-01、MNU、WASM 系列照過。
- 抓錯檢查：讓服務不隱藏專案名稱 → `DashboardApiTests` 失敗。驗完已還原。
- 全套單元／API 與端對端照跑。
