# WASM 遷移 M2：版面需要的 API、頁面拒絕稽核、上傳中換頁確認（1.1.5 → 1.1.6）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：1.1.6
- 首次實作版本：1.1.6
- 最後核對日期：2026/11/10

使用者要求：

> 開始（M2 第三步：通知鈴、變更密碼、關於的 API，頁面拒絕稽核，上傳中換頁確認）

---

## 一、原因

- 1.1.5 起 WASM 頁與 Server 頁共用同一個外框，但 WASM 頁的通知鈴只有未讀數，變更密碼與「關於」也還沒有 API。
- 之後搬到 WASM 的頁面擋下使用者時，也要像 Server 頁一樣寫「頁面拒絕存取」稽核。
- 遷移期間往 WASM 頁是整頁載入，舊版頁面還在上傳的影音檔或附件會被中斷（以前在舊版頁面之間切換不會）。

## 二、修改

- **通知鈴兩邊共用**：`NotificationBell` 搬到 WASM 專案（命名空間不變），資料來源抽成 `INotificationSource`——Server 頁用 `ServerNotificationSource`（伺服器服務＋程序內通知事件，原本寫在鈴鐺裡的邏輯），WASM 頁用 `ApiNotificationSource`（API＋推播通道，重連後重查）。鈴鐺項目改用 `NotificationDto`，不再直接用資料庫實體。
- **新增 API**（都只需登入、只動自己的）：
  - 通知：`GET /api/v1/notifications`（最近 20 則）、`POST …/{id}/read`、`POST …/read-all`。標別人的通知照樣回成功但不動。
  - 變更密碼：`POST /api/v1/account/change-password`，規則與 Server 頁使用者選單的對話窗相同（至少 6 字、support 不可改、驗目前密碼），須改密碼的帳號也能呼叫，改完清掉標記。
  - 關於：`GET /api/v1/system/about`。伺服器端組資料抽成 `SystemAboutProvider`、畫面排版抽成 `AboutItems`，兩種頁面內容一致。
  - 頁面拒絕稽核：`POST /api/v1/audit/page-denied`，寫出的紀錄與 Server 頁相同（目標 `Page#路由`），`via=Wasm`；路由只收 `/` 開頭的單純路徑，免得任意內容寫進稽核。WASM 端用 `PageAccessApi.RecordPageDeniedAsync`。
- `SessionDto` 加 `SystemName`：WASM 頁的側邊欄標題改從這裡來，拿掉 1.1.5 寫死的名稱。
- WASM 頁的使用者選單出現「變更密碼」「關於」，通知鈴可開清單、全部標為已讀。
- **上傳中換頁確認**：`BrowserFileUploader` 記這條連線還在進行的上傳數。
  - 有上傳時往 WASM 頁，`Routes.razor` 先跳確認「影音檔或附件還在上傳，離開這頁會中斷上傳」，選留下就不離開；選離開會先拿掉瀏覽器的提醒，不會連問兩次。
  - 關分頁、重新整理時瀏覽器會提醒（`chunk-upload.js` 的 `setLeaveGuard`）；上傳結束就解除。
  - `BrowserFileUpload` 的釋放改成只做一次（計數才不會被扣兩次）。
- 文件：[開發慣例與限制速查](../architecture/開發慣例與限制速查.md) §1、[認證授權與權限機制](../security/認證授權與權限機制.md)、09 號「十、之三」。
- 版本 1.1.5 → 1.1.6。

## 三、測試

- 新增 `LayoutApiTests`：通知清單只有自己的、標別人的不會動到、全部已讀；變更密碼的目前密碼錯誤、太短、support、須改密碼帳號改完標記清掉且新密碼登得進去；關於的版本與設定一致；頁面拒絕稽核的目標與 `via=Wasm`、不合法路由回 400。授權守門白名單補齊並寫明理由。
- `PageAccessDeniedAuditTests` 改成同時掃 Server 頁與 WASM 頁，兩種呼叫都認。
- 新增端對端：
  - WASM-07：WASM 頁的通知鈴看得到清單、全部標為已讀後歸零；
  - WASM-08：WASM 頁變更密碼，太短會提示、打過字再取消要確認（`FormDirtyHelper` 在 WASM 修剪後也正常）、關於顯示的版本與伺服器一致；
  - L4-08：會議頁上傳中，關分頁會提醒、往 WASM 頁會跳確認，選留下網址不變、上傳照常完成，完成後提醒解除；
  - WASM-05 改讀共用通知鈴的未讀數。
- 抓錯檢查：拿掉導覽攔截 → L4-08 在確認框那步失敗；拿掉 beforeunload 提醒 → L4-08 失敗。驗完已還原。
- 全套單元／API 與端對端照跑，NTF-01（Server 頁通知鈴）照過。

## 四、已知事項

- 通知的「幾分鐘前」在 WASM 頁用瀏覽器的時鐘與時區計算；伺服器與使用者不在同一時區時會有落差（目前都在台灣，不影響）。
