## 一、原因

專案頁搬到 WASM（1.1.26）之前，頁面上「歷史會議」區塊與「抽出待辦」視窗用到的動作都要有 API：
- 會議紀錄的產生與編修；
- 逐字稿；
- PDF；
- 移出專案；
- 待辦 PDF；
- 待辦抽取。

會議紀錄頁的 API（1.1.20）掛的是「會議紀錄」權限，專案頁看的是「專案項目」權限。有專案權限、沒有會議紀錄頁權限的人在 Server 專案頁本來就能用這些功能，所以另開專案範圍的端點，不借用。

## 二、修改

### 2.1 `ProjectMeetingController`（路由 `api/v1/Project/{projectId}/…`）

| 端點 | 權限（專案項目） | 說明 |
|---|---|---|
| `GET meetings` | 檢視 | 專案底下的會議，不帶會議紀錄全文 |
| `GET meetings/{meetingId}` | 檢視 | 含全文 |
| `GET transcripts/selectable` | 檢視 | 「AI 轉會議紀錄」可選的逐字稿 |
| `GET prompt-templates/selectable` | 檢視 | 啟用中的提示詞 |
| `POST meetings/{meetingId}/draft` | 修改 | 產生會議紀錄並歸屬到這個專案，會花 AI 費用 |
| `PUT meetings/{meetingId}/draft` | 修改 | 修改全文 |
| `DELETE meetings/{meetingId}` | 修改或刪除任一 | 從專案移除，只限上傳者，服務層把關 |
| `GET meetings/{meetingId}/transcript` | 檢視 | 逐字稿全文 |
| `GET meetings/{meetingId}/transcript/file` | 匯出 | 下載逐字稿 |
| `POST meetings/{meetingId}/transcript/copied` | 匯出 | 複製逐字稿的稽核 |
| `POST meetings/{meetingId}/draft/pdf` | 匯出 | 會議紀錄 PDF，表頭帶專案名稱 |
| `GET todos/pdf` | 匯出 | 待辦 PDF 總覽 |

- 會議要屬於這個專案，不是的一律 404：不能拿 A 專案的權限動 B 專案的會議。產生會議紀錄例外，可以挑還沒歸屬的逐字稿。
- 稽核摘要照 Server 專案頁 `page=Project`，另加 `via=Api`。

### 2.2 `TodoExtractionController`（路由 `api/v1/todo-extraction`，都要「待辦事項」新增權限，同 Server 頁）

- `POST meetings/{meetingId}`：抽出候選，會花 AI 費用。連同先前加入過的標題、本專案未完成的待辦一起回傳。
- `POST todos`：加為新待辦，可掛到主待辦底下，稽核來源 `via=AiExtract`。
- `PUT todos/{todoId}`：用候選更新既有待辦，只改期限與負責人。

### 2.3 服務層補漏

已完成（封存）的專案不能再抽待辦：
- 以前只有 Server 頁把按鈕藏起來，直接呼叫服務擋不住，照樣會花 AI 費用；
- 現在 `TodoExtractionService.ExtractAsync` 也擋，管理者不受限。

## 四、測試

- **授權矩陣**加 7 支專案會議端點。PDF、產生會議紀錄要假 AI／假 PDF，在 L2 驗。
- **L2 `ProjectMeetingApiTests`**（假 AI、假 PDF 的測試主機）：
  - 只有專案項目權限、沒有會議紀錄頁權限，也能看會議、改會議紀錄；
  - 同一位使用者看得到、但屬於另一個專案的會議，經這個專案的路由回 404；
  - 移出要修改或刪除任一：只有檢視 403；不是上傳者被擋；上傳者成功；
  - 兩種 PDF 由伺服器產生，稽核 `page=Project; via=Api`；
  - 待辦抽取：
    - 抽出候選、加入後記下來源會議、稽核 `via=AiExtract`；
    - 沒有待辦新增權限 403；
    - 已完成的專案被擋。
- **抓錯檢查**（驗完都已還原）：

  | 暫時改壞 | 結果 |
  |---|---|
  | 抽取不擋封存 | 抓到 |
  | 不檢查會議屬於這個專案 | 第一次沒抓到，見下方說明 |
  | 移出只接受修改權限 | 抓到 |

  第二項第一次沒抓到：測試用的是別的團隊的會議，本來就看不到。改成用看得到的另一個專案的會議後抓到。

全套單元／API 與端對端照跑；專案頁仍是 Server 頁，PRJ、AI 系列照過。
