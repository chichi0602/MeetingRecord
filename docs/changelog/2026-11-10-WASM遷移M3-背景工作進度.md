# WASM 遷移 M3：背景工作進度改由 API＋推播提供，WASM 頁也有進度面板（1.1.14 → 1.1.15）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：1.1.15
- 首次實作版本：1.1.15
- 最後核對日期：2026/11/10

使用者要求：

> M2 做完後自動做 M3，M3 也一次做完（每版全綠自動 commit 推送），做到 M3 里程碑報告再停。

---

## 一、原因

- M3 要搬會議、專案、待辦頁，上傳與轉錄進度都顯示在右下角的進度面板；面板原本只能在 Blazor Server 頁執行（直接讀伺服器記憶體裡的進度通知器）。
- 先讓面板在 WASM 頁也能用，後面幾版的上傳與會議頁才接得上。

## 二、修改

- **規則抽到伺服器的 `BackgroundJobBoard`**（`Web/Jobs`）：可見性（只看得到自己資料範圍內的會議的工作）、取消（上傳中用「上傳」種類）、關閉，原本寫在面板元件裡，現在 Server 頁面板與 API 共用同一份；階段文字也在這裡組好，兩邊顯示一樣。
- **新增 API `api/v1/jobs`**：清單、取消（會議紀錄修改權限）、關閉一則、全部關閉；看不到的工作回 404。
- **推播**：`JobProgressHubBridge` 訂閱兩個進度通知器，節流後（最多每 0.5 秒一次）推不帶資料的 `JobsChanged`，WASM 面板收到再查 API；推播通道重連後也重查。
- **面板搬到 WASM 專案**（`Web.Client/Components/Commons`，命名空間不變），資料來源改成 `IJobProgressSource`：Server 頁用 `ServerJobProgressSource`（直接讀通知器），WASM 頁用 `ApiJobProgressSource`（API＋推播）。畫面、文字、按鈕都不變。
- **WASM 版面掛上面板**：所有 WASM 頁右下角都看得到上傳、轉錄、會議紀錄生成的進度。
- 文件：[開發慣例與限制速查](../architecture/開發慣例與限制速查.md)、[Web API 端點目錄](../architecture/Web%20API%20端點目錄.md)、[認證授權與權限機制](../security/認證授權與權限機制.md)、畫面與欄位字典、介面視覺設計規範、09 號（新增「十、之四 M3 進度」、§4.4 實作現況）。
- 版本 1.1.14 → 1.1.15。

## 三、外部可見的行為變更

| 項目 | 以前 | 現在 |
|---|---|---|
| 背景工作進度 | 只有 Server 頁的面板 | 另有 `api/v1/jobs`，規則相同；WASM 頁也有面板 |
| 對外既有 API | — | 不變 |

## 四、測試

- 新增 `JobApiTests`：
  - 沒登入 401；
  - 清單只有自己資料範圍內的工作，上傳中、排隊中的階段文字正確；
  - 只有檢視權限不能取消（403）；上傳中的取消記成「上傳」種類、不會留下「轉錄待取消」；會議紀錄生成可取消；看不到的工作 404；種類不對 400；
  - 關閉與全部關閉只動得到看得到的工作。
- 授權守門白名單加清單與兩個關閉端點並寫明理由；`LayoutMountTests` 加 WASM 版面要掛進度面板。
- 端對端：
  - L4-03（從面板取消上傳）、L4-04（進度推給協作成員）一行不改照過；
  - 新增 **WASM-10**：主責成員在會議頁上傳，停在 WASM 頁（儀表板）的協作成員面板即時出現「上傳中」並跑到完成，沒有團隊的人看不到；按「關閉」後這列消失。
- 抓錯檢查：
  - 拿掉可見性過濾 → `JobApiTests` 三個案例失敗；
  - 上傳中改用「轉錄」種類取消 → 取消案例失敗；
  - 拿掉推播 → WASM-10 失敗。
  - 驗完都已還原。
- 全套單元／API 與端對端照跑。
