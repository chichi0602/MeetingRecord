# WASM 遷移 M4：使用說明 API（1.1.28 → 1.1.29）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：1.1.29
- 首次實作版本：1.1.29
- 最後核對日期：2026/11/11

使用者要求：

> 繼續做 1.1.29，另開分支。

---

## 一、原因

M4 只剩使用說明頁 `/help`。頁面搬到 WASM（1.1.30）之前，頁上用到的兩件事要有 API：
- **讀說明內容**：以前是 Server 頁自己讀 Web 組件的內嵌資源；
- **問 AI 助理**：要逐段顯示、能停止。以前由 Server 頁直接呼叫服務，稽核也由畫面寫。

這版只開 API，`/help` 仍是 Server 頁，畫面與操作不變。

## 二、修改

### 2.1 新端點（`HelpController`，`api/v1/help`，都要「使用說明」檢視權限，同畫面）

| 端點 | 說明 |
|---|---|
| `GET manual` | 去掉檔頭的說明 Markdown（保留分類標記，前端用同一套解析切分類與搜尋），以及 AI 助理能不能用、不能用的原因 |
| `POST assistant/ask` | 問 AI 助理，回應是串流（一行一筆 JSON：`delta`／`done`／`error`） |

提問的規則：
- **檢查**：問題空白回 400「請輸入問題。」；對話串編號格式不對（要 `help:` 加 32 位 16 進位）回 400；沒設定 AI 回 400「AI 助理目前無法使用：…」。
- **管理員章節**：要不要送給 AI 由伺服器依呼叫者判斷，同 1.0.43 的規則：一般使用者不送，管理者全送。請求裡沒有這個欄位。
- **歷史對話**：前端帶已經回答成功的輪次，伺服器照舊只取最近 3 輪、每則截到 2,000 字。
- **失敗**：第一段文字前就失敗（例如額度用完）回 400；開始之後失敗送一筆 `error`。訊息與 Server 頁相同。
- **停止**：前端中斷請求，伺服器跟著停止呼叫 AI，帳本記成 Cancelled，不再繼續花費。
- **稽核由伺服器寫**：`Help.AiAsk`，內容同 Server 頁（問題字數、是否含管理員章節、模型、結果），另加 `via=Api`；停止或斷線也記得到。
- **AI 呼叫者**：`HelpAssistantService` 改經 `IAiCallerProvider`（同 1.1.28），帳本記到 API 呼叫者。

### 2.2 抽出共用

- **`HelpManualProvider`**（`Web/Helps`，Singleton）：讀內嵌說明檔、去 BOM、切檔頭、解析，讀一次就快取。Server 說明頁與 API 共用，`HelpView` 不再自己讀。
- **`HelpAssistantFailure.Describe`**（Business）：失敗訊息，Server 頁與 API 共用，文字不變。
- **`NdjsonStreamer`**（`Web/Streaming`）：AI 問答 API 的串流寫法抽出來，AI 問答與使用說明共用。它會回傳結果，讓呼叫端事後寫稽核。AI 問答 API 的行為不變。

## 四、測試

- **授權矩陣**加 `Help.Manual`。提問要假 AI，在 L2 驗 401／403。
- **L2 `HelpApiTests`**（假 AI 主機）：
  - 說明內容沒有檔頭、有分類標記、助理可用；
  - 提問：
    - 串流的各段加起來等於完成時的全文；
    - 帳本功能別是使用說明 AI 助理、使用者是呼叫者；
    - 稽核 `outcome=成功; via=Api`；
  - 送給 AI 的內容：一般使用者不含「管理員」分類，管理者含（從 AI 對話紀錄讀出實際送出的內容）；對話串編號照前端給的，沒給就由伺服器產生；
  - 問題空白、對話串編號格式錯回 400；未登入 401、沒有使用說明權限 403，且沒有呼叫 AI；
  - 串流途中中斷請求：帳本記 Cancelled、稽核 `outcome=停止`。連跑三次都過。
- **L2 `HelpApiWithoutAiTests`**（沒有設定 AI 的主機）：說明照給、標示助理不能用；提問 400。
- **抓錯檢查**（驗完都已還原）：

  | 暫時改壞 | 結果 |
  |---|---|
  | 送給 AI 的內容一律含管理員分類 | 抓到 |
  | 是否含管理員改成固定 true | 抓到 |
  | 拿掉提問的權限檢查 | 抓到 |
  | 不把請求的取消傳給服務 | 抓到 |

- **既有測試照過**：`HelpManualTests`、`HelpManualSearchTests`、`HelpAssistantTests`、`AiChatApiTests`（串流抽出後）、授權守門掃描。
- **全套**：單元／API 與端對端照跑，AI-02（Server 使用說明頁）照過。
