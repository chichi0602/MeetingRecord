# WASM 遷移 M4：使用說明頁搬到 WASM（1.1.29 → 1.1.30）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：1.1.30
- 首次實作版本：1.1.30
- 最後核對日期：2026/11/11

使用者要求：

> 把 M4 全部做完（每版全綠自動 commit 合回 main）。

---

## 一、原因

M4 的最後一頁：`/help` 改由 Blazor WebAssembly 執行。1.1.29 已經開好 API（說明內容、AI 助理串流），這版把頁面搬過去。畫面與操作不變。

## 二、修改

### 2.1 頁面

- `HelpView.razor(.cs/.css)` 搬到 `Web.Client/Pages/Helps/HelpPage.*`，`@page "/help"`。Server 的 `Pages/Helps/HelpPage.razor` 刪除。
- 標記、class、文字、按鈕都不變，AI-02 一行不改照過。
- **權限**：改用 `PermissionView`；被拒時經 API 寫頁面拒絕稽核。
- **說明內容**：改由 `GET api/v1/help/manual` 取得，在瀏覽器用同一套 `HelpManual` 切分類與搜尋。
- **問 AI 助理**：改由 `POST api/v1/help/assistant/ask`（`HelpApi`，讀串流）。
  - 頁面不再判斷管理者、不再寫稽核，都在伺服器；
  - **「停止」＝中斷請求**，伺服器跟著停止呼叫 AI；離開頁面也一樣。
- `WasmRoutes` 加 `/help`。

### 2.2 共用程式搬家

- **`HelpManual`**（含 `HelpCategory`、`HelpTopic`）從 Web 搬到 `Share/Helpers`；`StripDocumentFrontMatter` 從 `HelpView` 搬進 `HelpManual`。伺服器（`HelpManualProvider`，送給 AI 的內容）與 WASM 頁共用。
- **`HelpViewInterop`** 搬到 `Web.Client/Services`（命名空間不變），只在 WASM 端註冊。JS（`help-view.js`、`chat-scroll.js`）照舊全站載入。

### 2.3 端對端

- **新增 AI-05**：使用說明 AI 助理按「停止」。
  - **假 AI 加慢速標記**：提示詞含 `E2E-慢速` 時每段延遲 300 ms，來得及按停止。
  - **驗證**：
    - 回答出現「（已停止）」；
    - 「發問」恢復可按；
    - 伺服器把這次呼叫記成取消；
    - 稽核記「停止」。
- **L4-05**（Blazor Server 斷線重連）：使用說明頁不再是 Server 頁，改用稽核紀錄頁 `/audit-logs`（M5 才搬，只限管理者，改用管理者登入）。重連後的「仍可操作」改成用不存在的關鍵字查詢、清單變成空的，結果要經 Blazor 連線回來。
- **L4-08**（上傳中往舊版頁要確認）：目標改成 `/audit-logs`。確認框在導覽前出現，選留下不會真的進頁，所以沒有那頁的權限也不影響。

### 2.4 文件與版本

- 文件：
  - 使用說明 PRD、畫面與欄位字典、開發慣例與限制速查、測試指南；
  - 09 號「十、之五」。
- 版本 1.1.29 → 1.1.30。

## 三、外部可見的行為變更

| 項目 | 以前 | 現在 |
|---|---|---|
| 使用說明頁 | Blazor Server 頁 | WASM 頁。從還沒搬的頁（管理、監控）切過來會整頁載入一次，同其他已遷移的頁 |
| 「停止」 | 取消伺服器上的呼叫 | 中斷請求，伺服器跟著停止；帳本照樣記成取消，稽核照樣記「停止」 |

## 四、量測

- **說明解析時間**：在瀏覽器解析 `HelpManual.Parse`（約 80 KB，6 類＋104 張搜尋卡片的 HTML）約 300～480 ms。在 1 秒的門檻內，不另外改成搜尋時才渲染。
- **WASM 下載量**：見 M4 里程碑報告。這版只多了說明頁與 `HelpManual`，Markdig 早已在 WASM 端。

- **端對端**：
  - AI 系列 5 則（含新的 AI-05）、L4-05、L4-08、MNU 照過；
