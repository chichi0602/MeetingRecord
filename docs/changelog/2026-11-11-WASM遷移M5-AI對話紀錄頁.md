## 一、原因

1.1.38 已開好 `api/v1/ai-call-logs`。這版把 AI 對話紀錄頁 `/ai-call-logs` 搬到 WASM，畫面不變。

搬頁途中發現一個從 1.1.1 就存在的路由錯誤：**帶查詢字串的 WASM 頁會無限重載**，這版一起修好。

### 2.2 修正：帶查詢字串的 WASM 頁無限重載

**現象**：從 Token 用量明細按「查看 AI 對話紀錄」（`/ai-call-logs?callId=…`），頁面一片空白、不停重載。

**原因**：
- Router 的 `NavigationContext.Path` **帶著查詢字串**，`ClientRoutes` 卻當它不含（註解也寫錯）。
- `WasmRoutes.IsWasm("/ai-call-logs?callId=…")` 回 false，WASM 端以為是 Server 頁就強制整頁載入。
- 伺服器看的是不含查詢字串的路徑，又送回 WASM 頁，於是一直重複。

伺服器的 `Routes.razor` 也有同樣問題：Server 頁連到帶查詢字串的 WASM 頁時，不會整頁載入。

**修正**：`WasmRoutes.IsWasm` 忽略 `?` 與 `#` 之後的部分，兩邊的 Router 一起修好；`ClientRoutes` 的註解改正。

### 2.3 端對端 MON-01 的檢查文字

`/ai-call-logs` 原本檢查「AI 對話紀錄」，但側邊選單也有這幾個字：頁面重載到空白時，選單閃出來那一下就讓 MON-01 照過。改成檢查頁面上的「清除此日之前」按鈕。
