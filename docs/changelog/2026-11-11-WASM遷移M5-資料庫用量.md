## 一、原因

M5 要把剩下的 8 個管理與監控頁搬到 WASM。第一頁選「資料庫用量」：
- 唯讀；
- 只限管理者；
- 沒有寫入動作；
- 不是 L4-05／L4-08 借用的稽核紀錄頁。

先用它定下 M5 的做法：
- 新的 `MonitoringController`，只限管理者；
- 報表型別搬到 Dtos；
- 頁面照搬。

## 二、修改

### 2.1 API（`MonitoringController`，`api/v1/monitoring`，整個 Controller `[AdminOnly]`）

| 端點 | 說明 |
|---|---|
| `GET database-usage` | SQLite 檔案大小、頁面配置、各資料表（同畫面上半部）；讀取失敗時報表本身帶 `errorMessage` |
| `GET storage-usage` | 各外部目錄大小與檔案數、各磁碟可用空間（同畫面下半部）。影音目錄可能很大，所以和上一支分開，畫面先顯示資料庫 |

- 非管理者回 403，並寫拒絕稽核「缺少權限：管理者」；未登入回 401。
- 後面幾版的監控頁也會加在這個 Controller。

### 2.2 型別搬到 Dtos

- `DatabaseUsageReport`、`TableUsage`、`SizeEstimateMethod` 從 `Web/Diagnostics` 搬到 `Dtos/Diagnostics`；
- `StorageUsageReport`、`DirectoryUsage`、`DriveUsage` 也搬過去。

計算屬性標 `[JsonIgnore]`。`StorageUsageReport.Warnings` 從唯讀屬性改成 `init`，從 JSON 還原時才不會掉。

### 2.3 頁面

- `DatabaseUsageView.razor(.cs/.css)` 搬到 `Web.Client/Pages/Monitoring/DatabaseUsagePage.*`，`@page "/database-usage"`；刪掉 Server 的 `Pages/Monitoring/DatabaseUsagePage.razor`。
- 畫面、文字、卡片、表格都不變。
- 管理者判斷改用 `PermissionView.IsAdmin`，被拒時經 API 寫頁面拒絕稽核。
- `WasmRoutes` 加 `/database-usage`。

### 2.4 文件與版本

- 文件：
  - 資料庫用量 PRD、Web API 端點目錄、認證授權；
  - 畫面與欄位字典、架構總覽、速查；
  - 09 號新增「十、之六 M5 進度」。
- 版本 1.1.31 → 1.1.32。
