# WASM 遷移 M6：首頁與找不到頁搬到 WASM（1.1.44 → 1.1.45）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：1.1.45
- 首次實作版本：1.1.45
- 最後核對日期：2026/11/11

使用者要求：

> 需要做 M6 並且一次性做完。

---

## 一、原因

M5 後應用程式的頁面全部是 WASM，但首頁 `/`（開場畫面）、`/not-found`、`/Error` 仍靠 Blazor Server 執行：
- 開場畫面在 Blazor Server 連線裡做登入檢查再導到會議紀錄；
- `/Error` 被當成互動頁，拿不到 `HttpContext`。

要拆掉 Server 互動模式（1.1.46），得先把它們處理掉。

## 二、修改

### 2.1 首頁與找不到頁搬到 WASM

- **`/`**（`Web.Client/Pages/HomePage.razor`）：
  - 登入狀態（未登入、停用、須改密碼）交給 `WasmLayout` 處理；
  - 通過後直接換到 `/meetings`（`replace`，上一頁不會回到首頁），去處同以前開場畫面檢查通過後。
- **`/not-found`**（`Web.Client/Pages/NotFoundPage.razor`）：
  - 改成中文「找不到這個頁面」，附回會議紀錄的連結；
  - 同時是 `ClientRoutes` 的 `NotFoundPage`；
  - 伺服器回 404 時照舊轉到這裡（`UseStatusCodePagesWithReExecute`）。
- **刪除**：Server 的 `Home`、`SplashView`（含樣式）、`NotFound`、`EmptyLayout`，以及範本殘留的 `Counter`、`Weather`。

### 2.2 路由判斷反過來：`WasmRoutes` → `ServerPageRoutes`

- 以前列「已搬到 WASM 的頁」，現在改列「仍由伺服器處理的頁」：`/Auths/*`（登入、登出、等待核准）與 `/Error`。
- 其餘一律是 WASM 頁；同樣忽略查詢字串與錨點（1.1.39 的教訓）。
- `App.razor`、兩邊的 Router 改用它。
- 伺服器頁一律靜態算繪，不再帶互動模式，`App.RenderModeForPage` 移除。

### 2.3 錯誤頁

`/Error` 改成靜態算繪（`[ExcludeFromInteractiveRouting]`，用 `NoFooterLayout`），拿得到 `HttpContext`、顯示得出 Request ID。

### 2.4 端對端

- **L4-08**：上傳中往「伺服器頁」要先確認，目標從 `/not-found` 改成登出頁 `/Auths/Logout`（`/not-found` 已是 WASM 頁）。上傳中按登出本來就該先問。
- **NAV-01**（新）：
  - 打開 `/` 會到會議紀錄；
  - 亂打網址顯示「找不到這個頁面」，且只載入一次（不會在伺服器與瀏覽器之間來回重載）；
  - 全程沒有 Blazor Server 連線（`/_blazor`）。

### 2.5 文件與版本

- 文件：
  - 首頁與導覽 PRD、畫面與欄位字典、介面視覺設計規範、AI 對話紀錄 PRD；
  - 開發慣例速查、架構總覽、測試指南；
  - 09 號新增「十、之七 M6 進度」。
- 版本 1.1.44 → 1.1.45。

## 三、外部可見的行為變更

| 項目 | 以前 | 現在 |
|---|---|---|
| 打開 `/` | 品牌開場畫面（系統名稱、版本、載入中），檢查通過後導到會議紀錄 | 短暫顯示「載入中…」，接著換到會議紀錄 |
| 找不到頁 | 英文「Not Found」 | 中文「找不到這個頁面」，可回會議紀錄 |
| 錯誤頁 `/Error` | 互動頁，拿不到 Request ID | 靜態頁，顯示 Request ID |

## 四、測試

- **單元 `ServerPageRoutesTests`**（取代 `WasmRoutesTests`）：
  - 登入、登出、等待核准、錯誤頁（不分大小寫、帶查詢字串與錨點）判斷成伺服器頁；
  - `/`、`/not-found`、`/meetings`、帶查詢字串的 WASM 頁、`/Auths`、`/Errors`、`/counter` 都是 WASM 頁。
- **端對端**：NAV-01 通過；L4-08（改用登出頁）、MON-01／02 照過。
- **抓錯檢查**：讓 `ClientRoutes` 對未知網址強制整頁載入 → NAV-01 失敗；已還原。
- **全套**：單元／API 與端對端全綠。
