## 五、核對時發現、這版沒處理的事

- **WASM 頁的 .NET 例外不會進系統例外紀錄**：
  - 瀏覽器端只攔 JS 的 `error`／`unhandledrejection`。
  - 頁面被 `ErrorBoundary` 接住的 .NET 例外只寫到瀏覽器主控台。
  - 遷移前的 `LoggingErrorBoundary` 會在伺服器記錄並給追蹤碼。
  - 系統例外紀錄頁的說明仍寫「使用者回報的錯誤追蹤碼可以直接貼進關鍵字查詢」。
  - 要不要補回由使用者決定。
- **程式碼裡的歷史註解**：約 190 處提到「Server 頁」、circuit、`CheckAccessAction` 等，分散在約 120 個檔案。
- **`CurrentUserService`**：正式程式裡已沒有地方寫入它，但幾個服務仍先讀它。
- `docs/changelog/2026-10-16-使用說明AI助理.md` 有一個本來就斷的連結（`AI用量分析-prd.md` 已改名為 Token 用量），歷史文件不改內容。
