# 註解夾在對話框屬性列造成頁面錯誤（1.1.61 → 1.1.62）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：1.1.62
- 首次實作版本：1.1.62
- 最後核對日期：2026/11/13

製作宣傳短片時截取系統畫面，發現兩個現象：

1. **待辦事項頁打不開**：一進去就顯示「這個頁面發生未預期的錯誤」。
2. **每一頁底部都跳「An unhandled error has occurred」**。

瀏覽器主控台的錯誤：

> InvalidOperationException: Object of type 'AntDesign.Modal' does not have a property matching the name '（一整段註解）'

---

## 一、原因

1.1.19 把表單對話框改成單向 `Visible` 時，說明註解寫在 `<Modal` 的屬性列中間（`Class="…"` 與 `Visible="…"` 之間）。
Razor 編譯得過，但執行時把整段註解當成**參數名稱**傳給 `AntDesign.Modal`，元件找不到同名屬性就丟例外，所在的元件整個渲染失敗。

共 7 處：

| 檔案 | 影響 |
|------|------|
| `Components/Layout/AppShell.razor`（變更密碼對話框） | 版面外框每頁都有，所以每一頁底部都跳錯誤列 |
| `Pages/Todos/TodoPage.razor` | 待辦事項頁整頁顯示錯誤 |
| `Pages/Categories/CategoryPage.razor` | 同類寫法 |
| `Pages/Teams/TeamPage.razor` | 同類寫法 |
| `Pages/PromptTemplates/PromptTemplatePage.razor` | 同類寫法 |
| `Pages/Admins/MyUserPage.razor` | 同類寫法 |
| `Pages/Admins/RoleViewPage.razor` | 同類寫法 |

`MeetingPage.razor`、`ProjectPage.razor` 的同一段說明本來就寫在標籤前一行，沒有問題。

## 二、修正

- 7 處註解原文不動，從屬性列移到 `<Modal` 的前一行。
- 新增 `RazorMarkupTests.RazorComments_ShouldNotSitInsideATag`：掃所有 `.razor`，註解開始符號前最近的 `<` 若接英文字母、且兩者之間沒有 `>`（屬性值裡的 `=>` 先排除），就判定夾在標籤屬性列裡。
- 〈開發慣例與限制速查〉「Razor 註解的兩個坑」第一點補上這次的案例與守門測試。

## 三、驗證

- 新測試在還原 7 個頁面時失敗、修正後通過（`RazorMarkupTests` 3 則全過）。
- 本機實跑：待辦事項、分類清單、團隊清單、提示詞清單、使用者管理、角色管理、會議紀錄頁都能正常載入，主控台沒有新的錯誤；待辦、分類、團隊、提示詞的「新增」對話框能打開。
- 依使用者指示未跑全套測試。
