# 會議紀錄分享連結（1.1.66 → 1.1.67）

- 文件狀態：已實作
- 現行系統版本：1.1.67
- 首次實作版本：1.1.67

使用者需求：

> 如果我想要在專案項目內的每筆紀錄 多一個分享按鈕 以url的方式跟別人分享這個紀錄 他點進來 就可以直接打開當筆會議紀錄頁面

使用者決定：
- **要登入、照原本權限**：連結只是捷徑，不開公開存取（系統沒有公開專案）。
- 按鈕放在**清單列上**，以及**「會議紀錄與逐字稿」視窗裡**。

---

## 一、連結

- 格式：`{網站根網址}projects?projectId=P&meetingId=M`。
- 帶 `projectId` 的原因：
  - 專案頁的 API 都以專案為範圍。
  - 使用者可能只有「專案項目」權限、沒有「會議紀錄」權限，所以不能走 `api/v1/Meeting/{id}`。

## 二、按鈕

- 清單操作欄多一顆「**複製分享連結**」（`share`），條件同「會議紀錄與逐字稿」（有會議紀錄或逐字稿）。
- `MarkdownEditorModal` 新增 `CanShare`／`OnShare`：唯讀時底部有「**複製連結**」，兩個頁籤都有。
  - 只有專案頁開啟。會議頁不開：未歸屬的會議只有上傳者看得到，分享沒有意義。
- 用 `ClipboardInterop` 複製，成功提示「對方要登入，而且有這個專案的權限才看得到」。
  - 瀏覽器不允許自動複製時，改跳對話框顯示網址讓使用者自己複製。

## 三、打開連結（`ProjectPage`）

- 用 `[SupplyParameterFromQuery]` 收 `projectId`／`meetingId`。
  - `OnInitializedAsync` 先選連結的專案，不先載「上次選的專案」。
- 在 `OnParametersSetAsync` 處理，寫法照 `TodoPage` 的 `todoId`：
  - 頁面開著時再點另一個連結也會處理。
  - 用已處理過的值擋重複開窗。
- 處理流程：
  - 專案看不到 → 提示「找不到這個專案，可能已經被刪除或你沒有權限看。」
  - 專案被「使用中」範圍或篩選擋掉（例如已完成的專案）→ 放寬成「全部」並清空篩選，再切過去。
  - 會議不在這個專案、或沒有內容 → 提示「找不到這筆會議紀錄，可能已經從專案移除或你沒有權限看。」
  - 找到 → 呼叫原本的 `OnOpenDraftModalAsync`。取單筆時伺服器照舊檢查專案權限。
- 不寫入「上次選的專案」：點連結不代表要改預設。
- 未登入：伺服器原本就會導到登入頁並帶 `ReturnUrl`（含查詢字串），登入後回到這個網址。

## 四、驗證

- 這次沒改伺服器，權限沿用既有 API：別的專案的會議回 404，已有測試。
- 相關測試共 269 個全部通過：`RazorMarkupTests`、`WebClientArchitectureTests`、`ProjectMeetingApiTests`、`MeetingApiTests`、`ApiIntegrationTests`。
- `MeetingRecord.Web.Client` 建置成功。依專案規定，這次沒有跑全套測試。
- 實機待驗：
  1. 列上按「複製分享連結」，貼到新分頁 → 切到該專案並打開那筆。
  2. 登出後貼連結 → 先到登入頁，登入後回來並打開。
  3. 用沒有該專案權限的帳號打開 → 出現「找不到…」提示。
  4. 已完成專案的連結 → 自動切到「全部」並打開。
  5. 視窗裡的「複製連結」同樣可用。
