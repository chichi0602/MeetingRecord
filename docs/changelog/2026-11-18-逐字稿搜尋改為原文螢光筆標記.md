# 逐字稿搜尋改為原文螢光筆標記（1.1.69 → 1.1.70）

- 首次實作版本：1.1.70
- 最後核對日期：2026/11/18

## 問題

1.1.69 新增的逐字稿搜尋，每個符合的字（例如「很」）都被拆成獨立一行、整行塗黃，原文被切得支離破碎。使用者希望像 Google／Chrome 的「尋找」一樣，只在原文裡用螢光筆標出那幾個字。

## 原因

逐字稿容器同時掛了 `.markdown-editor-pane`，那條規則是 `display: flex; flex-direction: column`。搜尋時內容被拆成「文字＋`<mark>`＋文字」多個節點，flex 容器把每個節點都排成獨立的一列並撐滿整寬。沒搜尋時只有一個文字節點，所以平常看不出來。

## 修改

`MeetingRecord.Web.Client/Components/Commons/MarkdownEditorModal.razor.css`：

- `.markdown-editor-transcript` 加 `display: block`，蓋掉 pane 的 flex，文字與標記回到同一行內排列；捲動不受影響。
- 螢光筆配色照 Chrome 尋找：其他符合的字黃色 `#ffff00`，目前這一筆橘色 `#ff9632`；拿掉外框，加 2px 小圓角。

搜尋列（輸入框、第 i／共 n 筆、上一筆／下一筆、Enter 跳下一筆）不變。
