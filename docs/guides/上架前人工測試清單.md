# 上架前人工測試清單

- 文件版本：1.12
- 文件狀態：維護中
- 現行系統版本：1.0.32
- 首次實作版本：0.4.110
- 最後核對日期：2026/10/15

上架前依序逐項人工驗證整個系統。請照段落順序做：前面段落建立的資料，後面會用到。

**使用方式**

- 每一項做完，在「結果」欄填 ✅（通過）或 ❌（不通過）。
- 不通過時記下編號、使用的帳號、畫面訊息，回報後修正。

**注意事項**

- 同一個瀏覽器同時只能登入一個帳號，換帳號請用無痕視窗或另一個瀏覽器。
- 標「💰」的項目會呼叫 AI 並產生費用，每項測一次即可。
- 2-5、2-6、4-4、7-12、14-18、14-41、14-42 會實際改動或刪除資料，請只用測試資料操作。

自動化測試的範圍見 [測試指南](測試指南.md)；本清單補的是只能靠人工確認的畫面與流程。
