# testing — 測試報告

- 文件版本：1.1

- 首次實作版本：1.0.61

本目錄收納由 `scripts/Run-E2E.ps1`（內部呼叫 `scripts/New-TestReport.ps1`）自動產生的測試報告。報告格式與完成門檻見 [09-Blazor-WASM-遷移評估與測試策略](../planning/09-Blazor-WASM-遷移評估與測試策略.md) 第八、九節；怎麼執行見 [測試指南](../guides/測試指南.md) §3.1。

- 報告的第一到五節由腳本從 `.trx` 產生，**不要手改數字**；要更新請重跑腳本。
- 第六節（已知且接受的差異）與第七節（人工驗收與簽核）人工填寫。
- WASM 遷移完成時再跑一次，帶入 WASM 版的 `e2e.trx`（`-WasmE2ETrx`）就是並列兩版的最終報告。
