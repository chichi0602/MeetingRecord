本目錄收納由 `scripts/Run-E2E.ps1`（內部呼叫 `scripts/New-TestReport.ps1`）自動產生的測試報告。分層、執行方式與報告種類見 [測試指南](../guides/測試指南.md) §3.1。

- 報告的第一到五節由腳本從 `.trx` 產生，**不要手改數字**；要更新請重跑腳本。
- 第六節（已知且接受的差異）人工填寫；里程碑報告另有第七節（L6 人工驗收與簽核）。
- 不帶參數產生一般測試報告「日期-測試報告-版本.md」；`-Milestone Mx` 產生里程碑報告。
- 下表 1.1.51 以前的報告都是 **WASM 遷移期間的歷史紀錄**（M0 基準是當時的 Blazor Server 版），內容不再更新；遷移的測試策略與門檻見 [09-Blazor-WASM-遷移評估與測試策略](../planning/09-Blazor-WASM-遷移評估與測試策略.md) 第八、九節。
